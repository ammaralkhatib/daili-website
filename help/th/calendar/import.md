ได้ไฟล์ปฏิทิน (.ics) จากโรงเรียนหรือชมรมใช่ไหม daili จะคัดลอกกิจกรรมในไฟล์ลงในปฏิทินครอบครัวให้หนึ่งครั้ง

1. เปิด **ปฏิทิน** แล้วแตะปุ่มการตั้งค่า (รูปเฟือง) ที่มุมขวาบน
2. ใต้ **ปฏิทินอื่น ๆ** แตะ **เพิ่มปฏิทิน** แล้วแตะ **นำเข้าไฟล์ (.ics)** และเลือกไฟล์
3. ในหน้า **นำเข้าไฟล์ปฏิทิน** เอาติ๊กออกจากรายการที่ไม่ต้องการ แตะวันที่หรือเวลาเพื่อเปลี่ยน
4. แตะปุ่มเพิ่มที่ด้านล่าง

หรือเริ่มจากไฟล์ในแอปเมล แอปไฟล์ หรือในรายการดาวน์โหลด แล้วแชร์ไปที่ daili หรือบน Android ให้เปิดด้วย daili

กิจกรรมที่ผ่านไปแล้วและสิ่งที่ต้องทำที่เสร็จแล้วจะไม่ถูกนำเข้า รายการที่คุณมีอยู่แล้วจะไม่ถูกติ๊กไว้ตั้งแต่แรก กฎการทำซ้ำบางแบบคัดลอกไม่ได้ กิจกรรมเหล่านั้นจึงถูกเพิ่มแค่ครั้งเดียว สิ่งที่ต้องทำจะไปอยู่ในรายการที่คุณเลือกใน **เพิ่มไปที่**

> Note: ไฟล์จะถูกอ่านบนโทรศัพท์เครื่องนี้และไม่ถูกอัปโหลด การนำเข้าใช้ได้ในแอปบนโทรศัพท์ ใช้บนเว็บไม่ได้
