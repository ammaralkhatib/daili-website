เจอสูตรเด็ดในเน็ตใช่ไหม บันทึกไว้ได้โดยไม่ต้องพิมพ์เอง

![หน้า “สูตรอาหาร” ที่เปิดเมนู + อยู่ “นำเข้าจากลิงก์” ถูกวงไว้](meals-import-link)

1. คัดลอกลิงก์ของหน้าสูตรอาหาร
2. ที่หน้าแรก แตะ **สูตรอาหาร** แตะ **+** แล้วแตะ **นำเข้าจากลิงก์**
3. วางลิงก์ใน **ลิงก์สูตรอาหาร** หรือแตะ **วาง** แล้วแตะ **นำเข้า**
4. ตรวจสิ่งที่ daili เจอ แล้วแก้ส่วนที่ไม่ถูก จากนั้นแตะ **บันทึก**

ถ้าหน้าเว็บไม่มีข้อมูลสูตรอาหาร daili ก็ยังบันทึกชื่อและรูปภาพไว้ให้ ส่วนวัตถุดิบและขั้นตอนให้เพิ่มเอง

> Note: ลิงก์ Instagram, TikTok และ YouTube ไม่มีข้อมูลสูตรอาหาร ให้คัดลอกข้อความสูตรแทน แล้วใช้ **วางข้อความสูตรอาหาร**
