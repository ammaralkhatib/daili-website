โทรศัพท์ของคุณอาจรู้วันเกิดของคนในครอบครัวอยู่แล้ว นำเข้ามาในครั้งเดียวได้เลย

![แผ่นการตั้งค่าวันเกิด แถว “นำเข้าจากรายชื่อผู้ติดต่อ” ถูกวงไว้](birthdays-import)

1. ที่หน้าแรก แตะ **วันเกิด** แล้วแตะรูปเฟืองที่ด้านบน
2. แตะ **นำเข้าจากรายชื่อผู้ติดต่อ** แตะ **ต่อไป** แล้วอนุญาตการเข้าถึงรายชื่อผู้ติดต่อ
3. ติ๊กวันเกิดที่ต้องการ หรือแตะ **เลือกทั้งหมด**
4. เปิด **เตือนฉันในวันนั้น** ไว้ถ้าอยากได้การเตือน
5. แตะ **นำเข้า**

ถ้ายังไม่มีวันเกิดเลย คุณจะเห็น **นำเข้าจากรายชื่อผู้ติดต่อ** อยู่บนหน้าวันเกิดด้วย

> Note: รายชื่อผู้ติดต่อของคุณอยู่ในโทรศัพท์เท่านั้น จะอัปโหลดเฉพาะวันเกิดที่คุณติ๊ก: ชื่อกับวันที่ ไม่มีอย่างอื่น
