오래된 태블릿이 가족 화면이 돼요: **홈**, **주**, **월**, **사람**, **식단**, **목록**, **습관**, **남은 시간**. 연결한 부모의 방해 금지 시간에는 어두운 **밤** 화면이 돼요.

1. 태블릿에서 app.daili.app/board/pair를 여세요. 코드와 QR이 나와요.
2. 앱에서 **설정** → **벽걸이 화면** → **화면 연결**(관리자만)으로 가세요. 코드를 입력하거나 **QR 코드 스캔**을 누르세요. 컴퓨터에서는 그 주소에서 코드를 입력하세요.
3. **승인**을 누르세요.

컴퓨터를 가족 화면으로 쓰려면: 사이드 메뉴의 내 이름 → **환경설정** → **이 브라우저를 가족 화면으로 사용**.

> Note: 비공개 항목은 내 것도 보이지 않아요. 메모, 가계부, 생리 주기, 문서도 마찬가지예요.

없애려면: **가족** 또는 **벽걸이 화면** → **벽걸이 화면** → **삭제**. 연결한 부모가 가족을 떠나거나 관리자가 아니게 되어도 멈춰요. 태블릿에서는 **길게 눌러 나가기**를 누르고 있다가 **그만 사용**을 누르세요.

iPad: 홈 화면에 추가하고 열어서 **가족 화면 설정하기**를 누르세요. 설정 → 디스플레이 및 밝기 → 자동 잠금은 '안 함'으로. Android: Chrome → 앱 설치.
