다 쓴 목록이지만 남겨 두고 싶나요? 삭제하지 말고 보관하세요. 장보기 목록과 할 일 목록에서 쓸 수 있어요.

![목록 두 개가 있는 ‘보관된 목록’ 화면. 목록 메뉴의 ‘복원’에 동그라미가 쳐져 있어요.](lists-archive)

1. 목록 카드에서 **⋯** → **보관**을 누르세요. 목록 안에서도 **⋯**에 있어요. **되돌리기**로 바로 되살릴 수 있어요.
2. 보관한 목록은 목록 맨 끝의 **보관함 · N**에 있어요. 누르면 읽을 수 있지만 바꿀 수는 없어요.
3. 다시 꺼내려면 옆의 **⋯** → **복원**을 누르세요. **삭제**를 누르면 완전히 사라져요.
4. 목록을 다시 쓰려면 목록을 열고 **⋯** → **템플릿으로 저장**을 누르세요.
5. 다음에는 목록 화면에서 **+**를 누르고 **템플릿으로 시작하기**를 누르세요.
6. 템플릿을 쓰거나 이름을 바꾸거나 삭제하려면 목록 화면 위쪽의 **⋯** → **템플릿**으로 가세요.

![‘템플릿 선택’이 열린 ‘새 목록’ 화면. 템플릿 두 개가 있는 목록에 동그라미가 쳐져 있어요.](lists-templates)

템플릿에는 항목이 남지만, 체크, 날짜, 사람은 남지 않아요. 템플릿은 가족이 함께 써요. **나만 보기** 목록으로 만든 템플릿은 나만 써요.

> Note: 보관한 목록은 알림을 보내지 않아요.
