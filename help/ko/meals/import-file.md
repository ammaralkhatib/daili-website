Paprika에서 옮겨 오나요? 레시피를 사진까지 한 번에 가져오세요.

Paprika에서 Paprika 형식(.paprikarecipes 파일)으로 내보내고, 기기에 저장하세요. 예를 들어 ‘파일’ 앱이나 ‘다운로드’ 폴더에요. 메뉴 이름은 Paprika 버전마다 조금 다를 수 있어요.

1. 홈 화면에서 **레시피**, **+**, **다른 앱에서**를 차례로 누르고 파일을 고르세요.
2. 원하지 않는 레시피는 체크를 해제하세요. 이미 daili에 있는 레시피는 처음부터 체크가 해제되어 있어요.
3. **레시피 12개 가져오기**를 누르세요(숫자는 체크한 레시피 수예요). 끝날 때까지 daili를 열어 두세요.
4. **레시피로 이동**을 누르세요.

제목, 재료, 조리 단계, 인분, 시간, 출처 링크, 메모, 사진을 가져와요. 카테고리는 태그가 돼요.

> Note: 한 가족은 태그를 50개까지 쓸 수 있어요. 넘치는 카테고리는 추가되지 않아요. 긴 레시피는 줄어들어요(재료 100개, 조리 단계 50개까지). 마지막 요약 화면에서 알려 줘요.

> Note: 파일은 내 기기에서 읽어요. 가져온 레시피만 저장돼요. 다시 가져오면 이름과 링크가 같은 레시피는 건너뛰어요.

지금은 Paprika 파일만 돼요. app.daili.app에서는 쓸 수 없어요.
