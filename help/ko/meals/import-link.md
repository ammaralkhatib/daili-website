인터넷에서 좋은 레시피를 찾았나요? 받아 적지 말고 저장하세요.

![+ 메뉴가 열린 ‘레시피’ 화면. ‘링크에서 가져오기’에 동그라미가 쳐져 있어요.](meals-import-link)

1. 레시피 페이지의 링크를 복사하세요.
2. 홈 화면에서 **레시피**, **+**, **링크에서 가져오기**를 차례로 누르세요.
3. **레시피 링크**에 링크를 붙여 넣거나 **붙여넣기**를 누르세요. 그런 다음 **가져오기**를 누르세요.
4. daili가 찾은 내용을 확인하고 틀린 곳을 고치세요. 그런 다음 **저장**을 누르세요.

페이지에 레시피 데이터가 없어도 daili는 제목과 사진을 저장해요. 재료와 조리 단계는 직접 넣으세요.

> Note: Instagram, TikTok 링크에는 레시피 데이터가 없어요. 대신 레시피 글을 복사해서 **레시피 글 붙여넣기**를 쓰세요. YouTube는 **YouTube 동영상에서**를 쓰세요.
