1. 예산에서 **지출 추가**를 누르세요.
2. 금액을 입력하세요. 마지막으로 쓴 카테고리가 이미 선택돼 있어요.
3. 날짜는 위쪽에 있어요: **오늘**, **어제** 또는 다른 날.
4. 결제한 사람 줄을 누르면 낸 사람을 바꿀 수 있어요. 비용을 나누는 예산에서는 공동 비용인지도 정해요.
5. 금액이 적힌 버튼을 눌러 저장하세요.

![숫자 패드로 ₩34 지출을 추가하는 화면. 위쪽 오늘 버튼에 동그라미가 쳐져 있어요.](budget-entry)

들어오는 돈은 위쪽 **수입**을 누르세요. 반복, 청구서, 메모는 **더 보기: 반복, 청구서, 메모, 카드 또는 현금**에 있어요. 저장한 직후 **실행 취소**를 누르면 되돌릴 수 있어요.

홈 화면에서 가계부 타일의 **+**를 누르거나, 빠른 추가 → **지출**을 누르세요.

항목을 다시 추가하려면 항목을 오른쪽으로 밀거나, 항목을 열고 **더 보기: 반복, 청구서, 메모, 카드 또는 현금**에서 **다시 추가**를 누르세요. 오늘 날짜로 된 복사본이 열리면 저장하세요.

> Note: 오프라인이라 보내지 못한 지출은 보관돼요. 다음에 지출을 추가할 때 daili가 다시 보여 줘요.
