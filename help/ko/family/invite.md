가족 모두가 같은 캘린더, 목록, 생일을 봐요.

1. 홈 화면에서 **가족**을 누르세요. 지금 코드는 **멤버 초대** 아래에 나와요.
2. **멤버 초대**를 누르세요.
3. **코드**의 6자리 코드를 보내거나, **QR 코드**를 보여 주거나, **링크 공유**를 누르세요.
4. 초대받은 사람은 daili를 열고 **가족·그룹 들어가기**를 누른 다음 코드를 입력하거나 **QR 코드 스캔**을 눌러요.

![가족 화면. 지금 코드와 만료일이 아래에 적힌 ‘멤버 초대’에 동그라미가 쳐져 있어요.](family-invite)

코드 하나는 한 사람만 쓸 수 있어요. 다음 사람에게는 **멤버 초대**를 다시 누르세요. 코드나 링크는 이메일을 인증하기 전에도 공유할 수 있어요. iCloud 주소로 이메일 초대를 보냈나요? Apple이 저희 메일을 막을 때가 있으니, 코드나 링크도 직접 보내 주세요.

> Note: 코드는 7일 동안 쓸 수 있고, 언제까지인지 화면에 나와요. 다른 사람에게 보냈나요? **멤버 초대** 화면에서 **새 코드 받기**를 누르면 이전 코드는 더 이상 쓸 수 없어요.
