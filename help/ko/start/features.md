첫 가족을 만들거나 들어가면 바로 daili가 **Daili를 어디에 쓰고 싶으세요?**라고 물어봐요. 모든 카드가 처음에는 체크되어 있어요.

1. 카드를 누르면 기능 설명을 읽을 수 있어요.
2. 카드의 체크 상자를 누르면 꺼져요. 다시 누르면 다시 켜져요.
3. **계속**을 누르세요. 모두 켜 두려면 **건너뛰기**를 누르세요.

캘린더와 가족은 목록에 없어요. 항상 홈 화면에 있어요. 고른 내용은 **설정**의 **홈 화면**에서 언제든지 바꿀 수 있어요.

> Note: 생리 주기 카드는 홈 화면에 타일만 놓아요. 생리 주기는 타일을 누르고 짧은 설정을 마치면 시작돼요. 비공개 기능이라 이 휴대폰에만 저장되고, 가족 누구도 볼 수 없어요. 필요 없나요? 카드 체크를 해제하거나 나중에 타일을 숨기세요.
