daili를 쓰려면 계정이 필요해요.

![로그인 화면. 위쪽에 Google과 Apple이 있고, 아래쪽 ‘회원가입’ 막대에 동그라미가 쳐져 있어요.](start-sign-in)

1. daili를 열고 **시작하기**를 누르세요. 새 휴대폰에서는 **계정 만들기** 화면이 열려요.
2. 아래쪽 막대로 화면을 바꿔요: **회원가입** 또는 **로그인**.
3. 위쪽의 **Google로 계속하기**나 **Apple로 계속하기**를 누르세요. 이메일로 하려면 **또는 이메일로** 아래에 이메일과 비밀번호를 입력하고 **로그인**을 누르세요.
4. 이메일로 처음 쓰나요? 이름과 이메일을 입력하고, 비밀번호를 두 번 입력한 다음 **계정 만들기**를 누르세요.
5. 비밀번호를 잊었나요? **비밀번호를 잊으셨나요?**를 누르고, 이메일을 입력한 다음 **재설정 링크 보내기**를 누르세요.

![계정 만들기 화면. ‘Google로 계속하기’와 ‘Apple로 계속하기’ 버튼에 동그라미가 쳐져 있어요.](start-register)

비밀번호는 8자 이상이어야 해요. 다음으로 사진과 이름을 넣고, 가족을 만들거나 들어가요.

계속하면 **이용약관**에 동의하게 돼요. daili가 데이터를 어떻게 다루는지는 **개인정보 처리방침**에서 설명해요.

> Note: **Apple로 계속하기**는 iPhone에만 있어요. Android에서는 Google이나 이메일을 쓰세요. daili를 다시 설치하면 다시 로그인해야 해요.
