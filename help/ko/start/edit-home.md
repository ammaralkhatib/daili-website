홈 화면에 어떤 타일을 어떤 순서로 보여 줄지 바꿀 수 있어요.

![편집 모드의 홈 화면. 타일마다 ×가 있어요. 오른쪽 아래 ‘완료’ 버튼에 동그라미가 쳐져 있어요.](start-edit-home)

1. 홈 화면에서 타일이 흔들리기 시작할 때까지 아무 타일이나 길게 누르세요.
2. 타일을 새 자리로 끌어다 놓으세요.
3. 타일의 **×**를 누르면 숨겨져요. **+**를 누르면 숨긴 타일이 다시 나타나요.
4. 오른쪽 아래의 **완료**를 누르세요.

**설정**의 **홈 화면**에서도 똑같이 할 수 있어요. 타일을 켜거나 끄고, 손잡이를 잡고 끌어서 옮기세요.

> Note: 배치는 이 휴대폰에만 저장돼요. 가족은 각자 자기 홈 화면을 꾸며요.
