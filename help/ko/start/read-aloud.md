daili가 휴대폰 자체 목소리로 내 하루를 읽어 줘요. 어디로도 아무것도 보내지 않아요.

![+ 옆에 말하는 얼굴 모양의 읽어 주기 버튼이 있는 홈 화면. 읽어 주기 버튼에 동그라미가 쳐져 있어요.](home-read-aloud)

1. 홈 화면에서 **+** 옆의 말하는 얼굴 버튼을 누르세요. **오늘**에 보이는 일정, 할 일, 습관, 장보기, 식사, 생일을 들려줘요.
2. 다시 누르면 멈춰요. 홈 화면을 떠나도 멈춰요.
3. 길게 누르면 설정이 열려요.

**설정** → **읽어 주기**에서 **속도**와 **음성**을 고르고 **샘플 듣기**를 누르세요. 버튼을 숨기려면 **홈에 버튼 표시**를 끄세요.

![홈에 버튼 표시, 속도, 음성이 있는 읽어 주기 설정. 홈에 버튼 표시 스위치에 동그라미가 쳐져 있어요.](settings-read-aloud)

로봇 같은 목소리인가요? 더 자연스러운 목소리를 무료로 받으세요. iPhone: **설정** 앱 → **손쉬운 사용** → **Read & Speak** → **음성** → 내 언어 → **음성**. Wi-Fi에서 **(프리미엄)** 또는 **(향상됨)**이 붙은 목소리를 내려받으세요. Android: 홈 화면이나 이 설정에 **방법 보기**가 나오면 누르고, **음성 설치**를 누른 다음 내 언어를 내려받으세요. daili는 새 목소리를 저절로 써요.
