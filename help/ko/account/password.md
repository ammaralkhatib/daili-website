비밀번호는 프로필에서 바꿔요.

![프로필 화면. ‘계정’ 아래의 ‘비밀번호 바꾸기’에 동그라미가 쳐져 있어요.](account-password)

1. **설정**을 열고 맨 위의 내 이름을 누르세요.
2. **계정** 아래의 **비밀번호 바꾸기**를 누르세요.
3. **현재 비밀번호**를 입력하세요. 그런 다음 **새 비밀번호**와 **새 비밀번호 확인**을 입력하세요. 8자 이상이어야 해요.
4. **저장**을 누르세요. 다른 휴대폰과 브라우저에서는 로그아웃되니, 거기서는 새 비밀번호로 로그인하세요.

Google이나 Apple로 가입했나요? 그러면 아직 비밀번호가 없어서 줄에 **비밀번호 만들기**라고 나와요. 누르면 daili가 비밀번호를 만들 링크를 이메일로 보내요.

> Note: 비밀번호를 잊었나요? 로그인 화면에서 **비밀번호를 잊으셨나요?**를 누르면 링크를 이메일로 보내 드려요.
