学校或社团发来了日历文件（.ics）？daili 会把里面的日程复制到你的家庭日历，只复制一次。

1. 打开**日历**，点右上角的设置按钮（齿轮）。
2. 在**其他日历**下面，点**添加日历**，再点**导入文件（.ics）**，然后选择文件。
3. 在**导入日历文件**页面上，取消勾选你不要的。点日期或时间可以修改。
4. 点底部的添加按钮。

也可以从邮件、文件或下载里的文件开始：把它分享到 daili，或者在 Android 上用 daili 打开。

已经过去的日程和已完成的待办不会导入。你已经有的条目一开始不勾选。有些重复规则无法复制，这些日程只添加一次。待办会放进你在**添加到**里选的清单。

> Note: 文件只在这台手机上读取，不会上传。导入只能在手机 App 里用，网页版不行。
