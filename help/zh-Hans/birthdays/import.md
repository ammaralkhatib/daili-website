家人的生日也许已经存在你的手机里了。一次全部导进来吧。

![“生日设置”面板。“从通讯录导入”这一行被圈出。](birthdays-import)

1. 在主页上，点**生日**，再点顶部的齿轮。
2. 点**从通讯录导入**，再点**继续**，然后允许访问通讯录。
3. 勾选你想要的生日，或者点**全选**。
4. 想收到提醒，就让**当天提醒我**保持打开。
5. 点**导入**。

还没有任何生日的时候，“生日”页面上也能直接找到**从通讯录导入**。

> Note: 通讯录留在你的手机上。只有你勾选的生日会上传，而且只有名字和日期，没有别的。
