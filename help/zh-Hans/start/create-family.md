登录后，daili 会问你是创建一个家庭或群组，还是加入一个。

![新用户看到的欢迎页面。“创建家庭或群组”按钮被圈出。](start-create-family)

1. 点**创建家庭或群组**。
2. 在**家庭或群组名称**里输入名字，比如“李家”或“足球队”。
3. 选一个**颜色**。
4. 点**创建**。

这是你的第一个家庭？daili 会问：**你想用 Daili 做什么？** 选好主页要显示的内容，点**继续**，或者点**跳过**。

现在你就是所有者了。邀请页面会打开一次，你可以邀请其他人，或者点**稍后**。

一周从你所在国家习惯的那一天开始，并显示当地的公共假日。两者都可以在**日历** → 齿轮 → **每周开始于**和**节假日**里修改。

新账户？前面还有一步：**嗨！你是谁？** 选好你的头像，核对你的名字。点**继续**，或者**跳过**。

![“嗨！你是谁？”这一步，已选好头像并填好名字。](start-you-step)

> Note: 家里已经有人创建了家庭？那就别再建第二个。点**加入家庭或群组**，用他们的邀请码加入。
