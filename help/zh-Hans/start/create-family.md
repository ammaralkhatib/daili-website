登录后，daili 会问你是创建一个家庭或群组，还是加入一个。

![新用户看到的欢迎页面。“创建家庭或群组”按钮被圈出。](start-create-family)

1. 点**创建家庭或群组**。
2. 在**家庭或群组名称**里输入名字，比如“李家”或“足球队”。
3. 选一个**颜色**。
4. 点**创建**。daili 会打开你的新主页。

现在你就是所有者了。接下来邀请其他人，这样大家看到的安排都一样。

> Note: 家里已经有人创建了家庭？那就别再建第二个。点**加入家庭或群组**，用他们的邀请码加入。
