你可以决定主页显示哪些卡片，以及它们的顺序。每个卡片都能移动或隐藏，**笔记**也一样。

![编辑模式下的主页，每张卡片上都有 ×。右下角的“完成”按钮被圈出。](start-edit-home)

1. 在主页上长按任意一张卡片，直到卡片开始晃动。
2. 把卡片拖到新的位置。
3. 点卡片上的 **×** 隐藏它。点 **+** 把隐藏的卡片找回来。
4. 点右下角的**完成**。

在**设置**的**主页**里也能这样做：打开或关闭卡片，按住把手拖动排序。

> Note: 布局只保存在这台手机上。家里每个人各自设置自己的主页。
