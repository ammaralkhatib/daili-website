daili 可以用你手机自带的声音，把你的一天读给你听。什么都不会发送出去。

![主页上 + 旁边有一个说话的脸，就是朗读按钮。朗读按钮被圈出。](home-read-aloud)

1. 在主页上，点 **+** 旁边那个说话的脸。你会听到**今天**里显示的内容：日程、待办、习惯、购物、饭菜和生日。
2. 再点一次就停止。离开主页也会停止。
3. 长按它可以打开它的设置。

在**设置** → **朗读**里，选好**语速**和**语音**，再点**试听**。关掉**在主页显示按钮**就能隐藏这个按钮。

![朗读设置，有在主页显示按钮、语速和语音。“在主页显示按钮”开关被圈出。](settings-read-aloud)

听起来像机器人？免费换一个更好听的声音。iPhone：打开**设置** App → **辅助功能** → **Read & Speak** → **声音** → 你的语言 → **声音**。连上 Wi-Fi，下载一个标着**(premium)**或**(enhanced)**的声音。Android：主页或这些设置里出现**教我怎么做**时，点它，再点**安装语音**，然后下载你的语言。daili 会自动使用新声音。
