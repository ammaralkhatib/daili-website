Direkt efter att du har skapat eller gått med i din första familj frågar daili: **Vad vill du använda Daili till?** Alla kort är förbockade från början.

1. Tryck på ett kort för att läsa om det.
2. Tryck på rutan på ett kort för att stänga av det, eller slå på det igen.
3. Tryck på **Fortsätt**. Eller tryck på **Hoppa över** för att behålla allt på.

Kalender och Familj finns inte i listan; de stannar alltid på startskärmen. Du kan ändra ditt val när som helst i **Inställningar** under **Startskärm**.

> Note: Kortet Menscykel lägger bara en ruta på startskärmen. Själva Menscykel startar först när du trycker på rutan och gör den korta inställningen. Den är privat: den stannar bara på den här telefonen, och ingen i din familj kan se den. Inte något för dig? Bocka av kortet, eller dölj rutan senare.
