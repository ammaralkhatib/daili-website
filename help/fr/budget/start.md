Budget est gratuit pour tout le monde.

1. Sur l'écran d'accueil, touche **Budget**, puis **Nouveau budget**. Plus tard, tu le trouveras sous le nom du budget, en haut.
2. Choisis **Budget mensuel du foyer**, **Vacances**, **Fête** ou **Partir de zéro**. Foyer se répète chaque mois ; Vacances et Fête ne servent qu'une fois.
3. Choisis la **Devise** et, si tu veux, un **Plafond**.
4. Sous **Qui peut le voir**, choisis **Toute la famille**, **Choisir des personnes** ou **Moi uniquement**.
5. Touche **Créer le budget**.

![Un budget d'octobre avec ce qui reste, les soldes et les catégories. Le bouton + est entouré.](budget-start)

Touche **+** pour ajouter une entrée : montant, catégorie, **Titre**, **Date**, **Payé par**, **Moyen de paiement**, **Répéter** et une **Note**. Chaque catégorie peut avoir son propre plafond : **⋯** → **Catégories**.

Les flèches affichent les autres mois. Cherche, ou filtre par **Payé par**.

> Note: Seule la personne qui a créé un budget peut le rendre privé. Elle, ou un admin de la famille qui le voit, peut le modifier ou le supprimer dans **Paramètres**. Toute personne qui le voit peut y toucher **Exporter** pour obtenir un fichier CSV. Une nouvelle devise change le symbole, pas les montants.
