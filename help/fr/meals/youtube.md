Tu as vu un plat sur YouTube ? daili écrit la recette.

![L'écran Recettes avec le menu + ouvert. Depuis YouTube ou Instagram est entouré.](meals-youtube)

1. Copie le lien de la vidéo dans l'app YouTube (Partager → Copier le lien).
2. Sur l'écran d'accueil, touche **Recettes**, puis **+**, puis **Depuis YouTube ou Instagram**.
3. Colle le lien sous **Lien YouTube ou Instagram**, ou touche **Coller**. Puis touche **Lire**.
4. Vérifie ce que daili a trouvé, puis touche **Enregistrer**.

La recette sort dans la langue de daili. Sans ta propre photo, l'image de la vidéo s'affiche en haut. Touche ▶ pour la regarder sur YouTube. Pour garder une image, ajoute ta propre photo.

Lire une vidéo avec l'IA est réservé aux adultes (18+) ; daili te le demande une fois. Tout le monde peut importer une vidéo dont la description renvoie vers une page de recette. Sur app.daili.app, seules ces vidéos fonctionnent.

> Note: Seulement les vidéos publiques de 25 minutes maximum. Une lecture de vidéo avec l'IA utilise une action IA : 3 par mois sont gratuites, Daili Plus en donne 30. Une recette tirée du lien de la description est gratuite.
