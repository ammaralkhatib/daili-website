1. Ouvre **Paramètres** → **Notes** → **Images et enregistrements**.
2. Choisis **Sur ce téléphone** ou **Cloud Daili**.

![Images et enregistrements, avec Sur ce téléphone choisi et Cloud Daili en dessous.](notes-files)

**Sur ce téléphone** est gratuit et choisi par défaut. Les fichiers sont seulement sur ce téléphone, et dans sa sauvegarde sur iPhone. Les autres voient une petite pastille à la place.

**Cloud Daili** fait partie de Daili Plus : 5 Go par famille. Toutes les personnes avec qui la note est partagée voient les fichiers, sur tous leurs appareils.

Si tu partages une note dont les fichiers sont seulement sur le téléphone, daili demande : **Partager le texte seulement** ou **Déplacer les photos dans le cloud**. Un fichier en attente d’envoi affiche un badge nuage. Touche-le pour réessayer.

Quand Plus se termine, rien n’est supprimé : les fichiers du cloud y restent, les nouveaux restent sur le téléphone (**Cloud Daili (en pause)**).

Un dessin ne peut être modifié que sur le téléphone où il a été fait. Un dessin dans le cloud a besoin d’une connexion.

> Note: Sur Android, les images et les enregistrements des notes ne sont pas dans la sauvegarde du téléphone. Le Cloud Daili les garde en sécurité.
