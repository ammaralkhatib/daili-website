Dans Cycle, touche la roue dentée pour ouvrir les **Réglages du cycle**.

1. **Rappels** : **Rappel des règles** arrive quelques jours avant. **Demander si mes règles ont commencé** demande le lendemain de la plage prévue. L'écran verrouillé affiche seulement « Tu as un rappel. Touche pour ouvrir ».
2. **Confidentialité** : **Verrouiller Cycle** demande Face ID, ton empreinte ou le code du téléphone. Le sélecteur d'apps masque Cycle, et Android en bloque les captures d'écran. **Afficher le texte en clair sur l'écran verrouillé** montre les rappels en entier.
3. Toujours sous **Confidentialité**, **Afficher dans mon calendrier** : le calendrier de ton téléphone affiche une goutte, pleine si notée, en contour si prévue. La famille ne la voit jamais.
4. **Importer (CSV)** récupère un fichier **Exporter (CSV)** et garde les jours déjà présents.

![Réglages du cycle avec tes durées habituelles, les Rappels avec l'interrupteur des fournitures, et la section Confidentialité. Verrouiller Cycle est entouré.](cycle-settings)

Tes données restent sur ce téléphone et dans sa sauvegarde, jamais sur le serveur de daili. Garde iCloud Backup ou la sauvegarde Google activée.

> Note: Te déconnecter arrête les rappels. Supprimer ton compte efface les données sur ce téléphone. Plus d'infos dans la politique de confidentialité sur daili.app.
