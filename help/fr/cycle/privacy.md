Ouvre Cycle et touche la roue dentée pour accéder aux **Réglages du cycle**.

Sous **Rappels** : **Rappel des règles** avec **Jours avant**, un **Rappel pour noter** et l'**Heure du rappel**. Sur l'écran verrouillé, un rappel dit seulement « Tu as un rappel », sauf si tu actives **Afficher le texte en clair sur l'écran verrouillé**.

Active **Verrouiller Cycle** : Cycle te demandera Face ID, ton empreinte ou le code de ton téléphone. Il se verrouille à nouveau après une minute d'absence.

Tes données de Cycle restent uniquement sur ce téléphone et dans sa propre sauvegarde. Le serveur de daili ne les reçoit jamais. **Exporter (CSV)** enregistre une copie dans un fichier. **Supprimer toutes les données du cycle** les efface.

> Note: Te déconnecter garde tes données mais arrête les rappels. Supprimer ton compte les efface de ce téléphone ; une ancienne sauvegarde du téléphone peut encore les contenir. Plus d'infos dans la politique de confidentialité sur daili.app.
