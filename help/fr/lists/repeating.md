Une tâche récurrente est une tâche qui revient. Quand tu la coches, elle passe à sa prochaine échéance.

![La fiche de modification d'une tâche. Les choix de Répéter, Aucune, Tous les jours, Tous les quelques jours, Toutes les semaines et Tous les mois, sont entourés.](lists-repeating)

1. Ouvre une liste de tâches et touche la tâche.
2. Donne-lui une **Échéance**.
3. Sous **Répéter**, choisis **Tous les jours**, **Tous les quelques jours**, **Toutes les semaines** ou **Tous les mois**.
4. Pour **Toutes les semaines**, choisis les jours sous **Ces jours-là**. Pour **Tous les mois**, choisis le **Jour du mois**.
5. Touche **Enregistrer**.

Quand tu la coches, un message te dit quand elle revient.

> Note: **Répéter** est grisé tant que la tâche n'a pas d'échéance. Une tâche récurrente en a besoin pour avancer.
