Une tâche récurrente est une tâche qui revient. Quand tu la coches, elle passe à sa prochaine échéance.

![La fiche de modification d'une tâche avec tous les choix de Répéter. Toutes les quelques semaines est choisi, toutes les 2 semaines le mercredi. Les choix de Répéter sont entourés.](lists-repeating)

1. Ouvre une liste de tâches et touche la tâche.
2. Donne-lui une **Échéance**.
3. Sous **Répéter**, choisis **Tous les jours**, **Tous les quelques jours**, **Toutes les semaines**, **Toutes les quelques semaines**, **Tous les mois**, **Tous les quelques mois** ou **Tous les ans**.
4. Pour **Toutes les semaines**, choisis les jours sous **Ces jours-là**. Pour **Toutes les quelques semaines**, choisis aussi le nombre de semaines.
5. Pour **Tous les mois**, choisis le **Jour du mois**. Pour **Tous les quelques mois**, choisis aussi le nombre de mois : 6 pour tous les six mois.
6. Touche **Enregistrer**.

Avec **Tous les ans**, la tâche revient chaque année le jour de son échéance. Quand tu coches une tâche, un message te dit quand elle revient.

> Note: **Répéter** est grisé tant que la tâche n'a pas d'échéance. Une tâche récurrente en a besoin pour avancer.
