Dépense les étoiles des habitudes et des corvées pour des récompenses, comme une sortie au cinéma.

![La page Récompenses d'Emma : 19 étoiles à utiliser, la récompense familiale, Demandée – en attente sur Sortie glace, et Sortie au cinéma avec La demander. La demander est entouré.](habits-rewards)

1. Dans **Habitudes**, touche **Récompenses** en bas, puis **+**.
2. Choisis une idée. Sous **Pour**, choisis **Famille** ou **Toi**. Un admin peut choisir n'importe qui.
3. Règle le **Prix en étoiles** (une personne) ou les **Étoiles nécessaires** (famille), de 5 à 500. Touche **Enregistrer la récompense**.

![Le formulaire Nouvelle récompense avec Sortie au cinéma pour Emma. La ligne Prix en étoiles est entourée.](habits-reward-new)

La carte du haut montre les étoiles à utiliser. Assez pour ta récompense ? Touche **La demander**. Les étoiles sont mises de côté jusqu'à ce qu'un parent réponde. **Retirer** annule la demande.

![L'onglet Récompenses pour un parent. Attend ta réponse : Emma demande Sortie glace (25 étoiles), avec Pas maintenant et Accepter. La carte est entourée.](habits-reward-answer)

Les parents répondent sous **Attend ta réponse** : **Accepter** dépense les étoiles, **Pas maintenant** les rend. Les admins peuvent aussi toucher **La donner maintenant**. Si **Un adulte dit oui d'abord** est désactivé, demander dépense les étoiles tout de suite.

Une récompense familiale se remplit avec les étoiles que tout le monde gagne après sa création. Elle est pleine ? **Planifier** ajoute un événement ; ensuite, un admin touche **C'est fait**.

![Juste après une coche, le message +1 étoile pour toi avec le lapin montre les deux récompenses qui ont reçu l'étoile. Le message est entouré.](habits-star-toast)

![La fiche « Tu as gagné une récompense » pour Resto tous ensemble. Le bouton Planifier dans l'agenda est entouré.](habits-reward-reached)

> Note: Sur le web, les récompenses sont l'onglet **Récompenses** dans **Habitudes**.
