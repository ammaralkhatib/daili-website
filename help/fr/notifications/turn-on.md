daili peut te rappeler les événements, les tâches, les anniversaires et les habitudes, et te prévenir quand quelqu'un de ta famille change quelque chose. Pour cela, ton téléphone doit l'autoriser.

![Le haut de l'écran Notifications avec un message indiquant que les notifications sont désactivées. Activer les notifications est entouré.](notifications-turn-on)

1. Touche ta photo en haut de l'écran d'accueil pour ouvrir les **Paramètres**, puis touche **Notifications**.
2. Tant que les notifications sont désactivées, un message en haut le dit. Touche **Activer les notifications** dedans.
3. Ton téléphone te pose la question. Touche **Autoriser**.
4. Tu as dit non avant ? Alors le bouton indique **Ouvrir les réglages**. Il ouvre les réglages de ton téléphone pour daili. Active les notifications là-bas.

Le message disparaît dès que les notifications sont activées.

> Note: daili te le demande aussi tout seul peu après tes débuts, et quand tu règles ton premier rappel.
