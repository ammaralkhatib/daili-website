Toute ta famille voit le même agenda, les mêmes listes et les mêmes anniversaires.

1. Sur l'écran d'accueil, touche **Famille**. Ton code actuel s'affiche sous **Inviter un membre**.
2. Touche **Inviter un membre**.
3. Partage le code à 6 chiffres de **Code**, montre le **QR code**, ou touche **Partager le lien**.
4. La personne ouvre daili, touche **Rejoindre une famille ou un groupe** et saisit le code ou colle le lien, ou touche **Scanner le QR code**.

![L'écran Famille. Inviter un membre, avec le code actuel et sa date de fin en dessous, est entouré.](family-invite)

Tu viens de créer une famille ? Cet écran s'ouvre une fois tout seul, avec **Ajouter un enfant sans compte** et **Plus tard**.

Chaque code marche pour une seule personne. Le code et le lien marchent même avant que ton e-mail soit confirmé. Une invitation par e-mail demande l'adresse de la personne et ton e-mail confirmé : touche **Confirmer l'e-mail** à cet endroit. Apple bloque parfois nos e-mails vers iCloud, alors envoie aussi le code.

> Note: Un code est valable 7 jours. Envoyé à la mauvaise personne ? Touche **Obtenir un nouveau code** sur **Inviter des membres**. Tous les anciens codes ne marchent plus ; les invitations par e-mail restent.
