Une vieille tablette devient un écran familial : **Accueil**, **Semaine**, **Mois**, **Personnes**, **Repas**, **Listes**, **Habitudes** et **Compte à rebours**. Pendant les heures calmes du parent qui l'a connectée, elle s'assombrit et passe en **Nuit**.

1. Sur la tablette, ouvre app.daili.app/board/pair. Un code et un QR s'affichent.
2. Dans l'app : **Paramètres** → **Écran mural** → **Connecter un écran** (admins seulement). Saisis le code, ou touche **Scanner le QR code**. Sur un ordinateur, saisis le code à cette adresse.
3. Touche **Approuver**.

Un ordinateur comme écran : ton nom dans le menu → **Général** → **Utiliser ce navigateur comme écran familial**.

> Note: L'écran n'affiche jamais rien de privé, pas même tes propres éléments, ni les sections Notes, Budget, Cycle ou Documents.

Pour le retirer : **Famille** ou **Écran mural** → **Écrans muraux** → **Supprimer**. Il s'arrête aussi si le parent qui l'a connecté quitte la famille ou n'est plus administrateur. Sur la tablette : **Maintiens pour quitter**, puis **Ne plus utiliser**.

iPad : ajoute la page avec Sur l'écran d'accueil, ouvre-la et touche **Installer un écran familial**. Dans Réglages → Luminosité et affichage, règle Verrouillage automatique sur Jamais. Android : Chrome → Installer l'application.
