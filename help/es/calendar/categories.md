El color de un evento viene de su categoría. Así, «Deporte» se ve igual en todas partes. Cada familia empieza con seis: Familia, Trabajo, Colegio, Deporte, Salud y Tiempo libre.

![La pantalla Categorías de eventos con seis categorías. La fila Añadir categoría está marcada con un círculo.](calendar-categories)

1. En la pantalla de inicio, toca **Familia**.
2. En **Calendario**, toca **Categorías de eventos**.
3. Toca **Añadir categoría**, escribe un **Nombre**, elige un **Color** y toca **Añadir**.
4. Toca una categoría para cambiarle el nombre o el color. Toca **⋮** para eliminarla.

Para dar una categoría a un evento, toca **Categoría** en el evento. En **Calendario**, toca **Filtro** para ver solo una categoría.

> Note: Las categorías se comparten con toda la familia, y cualquiera puede cambiarlas. Una familia puede tener hasta 30.
