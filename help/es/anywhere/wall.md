Una tableta vieja se convierte en una pantalla familiar: **Casa**, **Semana**, **Mes**, **Personas**, **Comidas**, **Listas**, **Hábitos** y **Cuenta atrás**. Durante las horas de silencio del padre o la madre que la conectó, baja el brillo y pasa a **Noche**.

1. En la tableta, abre app.daili.app/board/pair. Aparecen un código y un QR.
2. En la app: **Ajustes** → **Pantalla de pared** → **Conectar una pantalla** (solo admins). Escribe el código o toca **Escanear código QR**.
3. Toca **Aprobar**.

Un ordenador como pantalla: tu nombre → **General** → **Usar este navegador como pantalla familiar**.

El primer toque pone la pantalla completa. El tablero se reinicia y se vuelve a conectar solo.

> Note: Nunca muestra cosas privadas, ni siquiera las tuyas, ni tampoco Notas, Presupuesto, Ciclo ni Documentos.

Para quitarla: **Pantalla de pared** → **Pantallas de pared** → **Quitar**. También deja de funcionar si quien la conectó sale o deja de ser admin. En la tableta: **Mantén pulsado para salir** y luego **Dejar de usar**.

iPad: usa Añadir a pantalla de inicio, abre el icono y toca **Configurar una pantalla familiar**. En Ajustes → Pantalla y brillo, pon Bloqueo automático en Nunca. Android: Chrome → Instalar aplicación.
