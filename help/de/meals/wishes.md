Schon wieder Pfannkuchen? Lass alle sagen, was sie gern essen möchten.

![Der Tab Plan mit dem geöffneten Fenster Wünsche und zwei Wünschen mit Planen-Buttons. Die Liste der Wünsche ist eingekreist.](meals-wishes)

1. Tippe auf dem Startbildschirm auf **Essensplan** und dann unten auf **Wünsche**.
2. Tippe auf **Wunsch hinzufügen**. Wähl ein Rezept oder gib ein Gericht ein und tippe dann auf **Wunsch hinzufügen**.
3. Um einen Wunsch einzuplanen, tippe daneben auf **Planen**, wähl einen Tag und eine Mahlzeit und bestätige.

Auch das Fenster zum Hinzufügen an einem Tag zeigt Wünsche, unter **Familienwünsche**. Das geplante Gericht zeigt, wessen Wunsch es war. Plant es jemand anderes, bekommt die Person mit dem Wunsch eine Benachrichtigung.

**KI-Plan** kann Wünsche nutzen. Sie kommen zuerst dran, einer pro Tag, wenn sie zum Abendessen passen.

Deine Wünsche können nur du und Admins bearbeiten oder löschen. Admins können auch für ein Kind ohne Anmeldung einen Wunsch hinzufügen.

Auf app.daili.app stehen die Wünsche in einer Zeile über der Woche, mit **+** zum Hinzufügen. Klick auf einen Wunsch und dann auf **Einplanen**.

> Note: Du willst die Benachrichtigung nicht? Schalte **Deine Essenswünsche** unter **Einstellungen** → **Benachrichtigungen** aus.
