Deine Familie kann eine eigene Gewohnheitsliste führen: Kategorien, die ihr benennt, und Gewohnheiten, die ihr gespeichert habt, um sie wieder zu starten.

1. Tippe in **Gewohnheiten** auf **+**.
2. Tippe auf dem Bildschirm **Gewohnheit starten** in der Reihe der Kategorien auf den Chip **Bearbeiten**.
3. Gib unter **Kategorien deiner Familie** einen Namen ein und tippe auf +. Mit den Buttons benennst du eine um, verschiebst oder löschst sie.
4. Tippe unter **Kategorien von Daili** auf das Auge, um eine auszublenden, die du nicht brauchst.

![Der Bildschirm Kategorien mit der Kategorie Morgenroutine. Das Feld Neue Kategorie ist eingekreist.](habits-categories)

Um eine Gewohnheit zu speichern, schalte in ihrem Formular **In meiner Gewohnheitsliste speichern** ein und wähle eine **Kategorie**. Sie erscheint dann unter **Gewohnheit starten**. Halte sie dort gedrückt und wähle **Bearbeiten**, **In Kategorie verschieben** oder **Löschen**.

> Note: Deine ganze Familie sieht sie. Wer eine erstellt hat, oder ein Admin, kann sie ändern. Nur Admins können die Kategorien von daili ausblenden.
