Manche Gewohnheiten gehen niemanden etwas an. Eine private Gewohnheit siehst nur du.

![Der Teil Mehr im Formular für eine neue Gewohnheit. Der Schalter Privat ist eingekreist.](habits-private)

1. Starte eine neue Gewohnheit, oder öffne eine von deinen und tippe auf den Stift.
2. Wähle unter **Wer** die Option **Nur ich**.
3. Schalte unter **Mehr** die Option **Privat** ein.
4. Tippe auf **Gewohnheit starten**, oder auf **Speichern**, wenn du eine änderst.

Die Gewohnheit zeigt jetzt ein Schloss und das Wort **Privat**.

> Note: Nur eine Gewohnheit mit **Nur ich** kann privat sein. Private Gewohnheiten bringen der Familie keine Energie und erscheinen nicht auf der Familientafel.
