Wie eine Einkaufsliste, aber eine Aufgabe kann auch eine Person, ein Fälligkeitsdatum und eine Erinnerung haben.

![Der Bildschirm Aufgaben mit einer Liste. Die Karte der Liste Haushalt ist eingekreist.](lists-todos)

1. Tippe auf dem Startbildschirm auf **Aufgaben** und dann auf eine Liste. Für eine neue Liste tippst du auf **+**, gibst unter **Name** einen Namen ein und tippst auf **Erstellen**.
2. Gib die Aufgabe unten in **Eintrag hinzufügen** ein und füg sie hinzu.
3. Tippe auf eine Aufgabe, um ihr eine Person unter **Zuständig**, ein Datum unter **Fällig am**, eine **Kategorie** oder eine **Notiz** zu geben.
4. Fertig? Tippe auf das Kästchen vor der Aufgabe. Sie rutscht nach unten zu **Erledigt**.
5. Um die Liste zu sortieren, tippe auf **⋯** und dann auf **Gruppieren nach**.

Wische eine Aufgabe nach links, um sie zu löschen, oder halte sie gedrückt, um sie zu verschieben.

In einer geteilten Liste macht das Schloss neben dem Sendepfeil deine nächsten Aufgaben privat, bis du die Liste verlässt.

Kein Netz? Du kannst trotzdem Aufgaben abhaken und hinzufügen. Das Abhaken einer wiederkehrenden Aufgabe und andere Änderungen brauchen eine Verbindung.

> Note: **Gruppieren nach** wird nur auf diesem Handy gespeichert.
