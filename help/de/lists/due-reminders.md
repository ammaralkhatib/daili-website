Eine Aufgabe kann einen Fälligkeitstag und eine Erinnerung haben. Die Erinnerung geht an die Personen, denen die Aufgabe zugewiesen ist, oder an alle, wenn sie niemand hat.

![Das Fenster zum Bearbeiten einer Aufgabe, mit der Erinnerung auf Zum Fälligkeitszeitpunkt. Das Feld Erinnerung ist eingekreist.](lists-due-reminders)

1. Während du eine neue Aufgabe eintippst, tippe über der Eingabeleiste auf **Heute**, **Morgen** oder **Datum wählen…**.
2. Für eine Erinnerung tippst du auf die Aufgabe. Tippe unter **Fällig am** auf **Fälligkeitsdatum hinzufügen**, falls sie keins hat, und auf **Uhrzeit hinzufügen** für eine Uhrzeit.
3. Wähle unter **Erinnerung** den Zeitpunkt, zum Beispiel **Zum Fälligkeitszeitpunkt**. Tippe dann auf **Speichern**.
4. Wenn die Erinnerung kommt, tippe auf **Erledigt** oder **15 Min. später**. Tippe auf die Erinnerung, um die Liste bei dieser Aufgabe zu öffnen.

**Jeden Tag erneut erinnern, bis erledigt** wiederholt sie täglich zur selben Uhrzeit, bis die Aufgabe abgehakt ist, höchstens 30 Tage nach dem Fälligkeitsdatum. Auch bei überfälligen Aufgaben.

![Das Fenster zum Bearbeiten einer Aufgabe. Jeden Tag erneut erinnern, bis erledigt ist eingekreist.](lists-remind-daily)

> Note: **Erinnerung** erscheint erst, wenn die Aufgabe ein Fälligkeitsdatum hat. Löschst du das Datum, verschwindet auch die Erinnerung.
