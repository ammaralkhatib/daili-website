Eine Aufgabe kann einen Fälligkeitstag und eine Erinnerung haben. Die Erinnerung geht an die Personen, denen die Aufgabe zugewiesen ist, oder an alle, wenn sie niemand hat.

![Das Fenster zum Bearbeiten einer Aufgabe mit Fälligkeitsdatum und Uhrzeit. Das Feld Erinnerung ist eingekreist.](lists-due-reminders)

1. Während du eine neue Aufgabe eintippst, tippe über der Eingabeleiste auf **Heute**, **Morgen** oder **Datum wählen…**.
2. Für eine Erinnerung tippst du auf die Aufgabe. Tippe unter **Fällig am** auf **Fälligkeitsdatum hinzufügen**, falls sie keins hat, und auf **Uhrzeit hinzufügen**, wenn du eine brauchst.
3. Wähle unter **Erinnerung** den Zeitpunkt, zum Beispiel **Am Morgen (9:00)**. Tippe dann auf **Speichern**.
4. Wenn die Erinnerung kommt, tippe auf **Erledigt**, um die Aufgabe abzuhaken, oder auf **15 Min. später**.

> Note: **Erinnerung** erscheint erst, wenn die Aufgabe ein Fälligkeitsdatum hat. Löschst du das Datum, verschwindet auch die Erinnerung.
