Mit einer Liste fertig, aber du willst sie behalten? Archiviere sie, statt sie zu löschen. Das geht bei Einkaufs- und Aufgabenlisten.

![Der Bildschirm Archivierte Listen mit zwei Listen. Wiederherstellen im Menü einer Liste ist eingekreist.](lists-archive)

1. Tippe auf der Karte einer Liste auf **⋯** → **Archivieren**. In einer Liste findest du es auch unter **⋯**. **Rückgängig** holt sie sofort zurück.
2. Archivierte Listen warten unter **Archiviert · N** am Ende deiner Listen. Tippe auf eine, um sie zu lesen. Ändern lässt sie sich nicht.
3. Um eine zurückzuholen, tippe daneben auf **⋯** → **Wiederherstellen**. **Löschen** entfernt sie endgültig.
4. Um eine Liste wiederzuverwenden, öffne sie und tippe auf **⋯** → **Als Vorlage speichern**.
5. Beim nächsten Mal tippst du bei deinen Listen auf **+** und dann auf **Mit einer Vorlage starten**.
6. Vorlagen nutzen, umbenennen oder löschen: **⋯** oben bei deinen Listen → **Vorlagen**.

![Der Bildschirm Neue Liste mit geöffnetem Vorlage auswählen und zwei Vorlagen. Die Vorlagenliste ist eingekreist.](lists-templates)

Eine Vorlage behält die Einträge, ohne Haken, Fälligkeiten oder Personen. Deine Familie teilt sich die Vorlagen. Eine Vorlage aus einer Liste mit **Nur ich** bleibt deine.

> Note: Eine archivierte Liste schickt keine Erinnerungen.
