Eine geteilte Notiz können auch andere ändern, wenn du es erlaubst.

1. Tippe in deiner Notiz bei **Wer kann sie sehen** auf **Ändern**, oder beim Schreiben auf den Chip **Nur ich**.
2. Wähle **Ganze Familie** oder **Mitglieder auswählen**.
3. Schalte **Andere dürfen bearbeiten** ein.

![Wer kann sie sehen mit Ganze Familie gewählt und Andere dürfen bearbeiten eingeschaltet. Der Schalter ist eingekreist.](notes-others-edit)

Die anderen sehen dann **Bearbeiten** in der Notiz. Sie können Titel, Text und Link ändern. Bilder können sie hinzufügen, wenn deine Familie die **Daili Cloud** hat. Nur du kannst sie löschen, anheften, Tags vergeben, eine Erinnerung setzen oder ändern, wer sie sieht.

Hat zuletzt jemand anderes die Notiz geändert, steht dort **Bearbeitet von** mit Name und Uhrzeit.

![Die Notiz Omas Besuch mit der Zeile Bearbeitet von Marco · Heute unter dem Titel. Die Zeile ist eingekreist.](notes-edited-by)

Hat jemand gespeichert, während du bearbeitet hast? daili fragt: **Die andere Version nehmen** oder **Meine als neue Notiz behalten** (eine private Kopie).

> Note: Stellst du die Notiz wieder auf **Nur ich**, wird **Andere dürfen bearbeiten** ausgeschaltet. Bei einer Änderung bekommt niemand eine Benachrichtigung.
