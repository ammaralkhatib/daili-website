Alle in deiner Familie sehen einen neuen Termin sofort.

![Der Kalender in der Monatsansicht. Der Button + unten rechts ist eingekreist.](calendar-add-event)

1. Öffne den **Kalender** und tippe unten rechts auf **+**.
2. Gib einen **Titel** ein.
3. Stell **Beginn** und **Ende** ein. Für einen ganzen Tag schaltest du **Ganztägig** ein.
4. Füg bei Bedarf mehr hinzu: **Wiederholung**, eine **Erinnerung**, eine **Kategorie** oder einen **Ort**.
5. Tippe auf **Speichern**.

Derselbe Termin an anderen Tagen, etwa Schichten? Tippe auf **Weitere Tage** (auch auf app.daili.app) und hake sie an. Jeder Tag wird ein eigener Termin. Die anderen bekommen eine einzige Benachrichtigung, ein paar Minuten später.

Unter **Für** wählst du, für wen der Termin ist, auch Kinder. Wählst du niemanden, gilt **Alle**. Nur die gewählten Personen mit Anmeldung bekommen seine Erinnerungen und Benachrichtigungen.

**Anhängen** fügt eine Aufgabe, einen Einkauf, ein Dokument oder ein Foto hinzu. Nach dem Speichern öffnet sich der Termin. Schließt du ihn, leuchtet er dort auf, wo er gelandet ist.

> Note: Du kannst einen Termin auch auf dem Startbildschirm hinzufügen: mit dem runden **+** oder dem **+** auf der Wochenkarte.
