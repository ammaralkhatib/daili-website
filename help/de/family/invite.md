Alle in deiner Familie sehen denselben Kalender, dieselben Listen und Geburtstage.

1. Tippe auf dem Startbildschirm auf **Familie**.
2. Tippe auf **Mitglied einladen**.
3. Teile den 6-stelligen Code unter **Code**, zeig den **QR-Code** oder tippe auf **Link teilen**.
4. Die andere Person öffnet daili, tippt auf **Familie oder Gruppe beitreten** und gibt den Code ein oder tippt auf **QR-Code scannen**.

![Der Familienbildschirm mit dem Button Mitglied einladen](family-invite)

> Note: Ein Code gilt 7 Tage, und der Bildschirm zeigt, bis wann. Danach tippst du wieder auf **Mitglied einladen** für einen neuen.
