Alle in deiner Familie sehen denselben Kalender, dieselben Listen und Geburtstage.

1. Tippe auf dem Startbildschirm auf **Familie**. Dein aktueller Code steht unter **Mitglied einladen**.
2. Tippe auf **Mitglied einladen**.
3. Teile den 6-stelligen Code unter **Code**, zeig den **QR-Code** oder tippe auf **Link teilen**.
4. Die andere Person öffnet daili, tippt auf **Familie oder Gruppe beitreten** und gibt den Code ein oder fügt den Link ein, oder sie tippt auf **QR-Code scannen**.

![Der Familienbildschirm. Mitglied einladen, darunter der aktuelle Code und sein Ablaufdatum, ist eingekreist.](family-invite)

Gerade eine Familie erstellt? Dann öffnet sich dieser Bildschirm einmal von selbst, mit **Kind ohne Konto hinzufügen** und **Später**.

Jeder Code gilt für eine Person. Code und Link funktionieren schon, bevor deine E-Mail bestätigt ist. Für eine Einladung per E-Mail brauchst du die Adresse der Person und deine bestätigte E-Mail: Tippe dort auf **E-Mail bestätigen**. Apple blockiert unsere E-Mails an iCloud manchmal, also schick zusätzlich den Code.

> Note: Ein Code gilt 7 Tage. An die falsche Person geschickt? Tippe unter **Mitglieder einladen** auf **Neuen Code holen**. Alle älteren Codes gelten dann nicht mehr; Einladungen per E-Mail bleiben.
