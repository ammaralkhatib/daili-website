Tippe auf einem verbundenen Familienbildschirm auf eine Aufgabe, einen Einkaufsartikel oder eine Gewohnheit, um sie abzuhaken.

Das zählt für die Person, zu der es gehört. Bei einem Einkaufsartikel, einer Aufgabe für niemanden oder für mehrere und einer gemeinsamen Gewohnheit kommt die Frage **Wer hat es erledigt?** Tippe auf dein Gesicht. Kinder ohne Login bekommen ihre eigenen Gewohnheiten gutgeschrieben.

**Rückgängig** erscheint 5 Sekunden lang. Nur so nimmst du hier einen Haken zurück. Eine wiederkehrende Aufgabe hat kein **Rückgängig**.

Das runde **+** oben rechts fügt einen Termin, eine Aufgabe, einen Einkaufsartikel oder eine Mahlzeit hinzu. Wähle zuerst, wer hinzufügt.

Belohnungen stehen unter den Gewohnheiten jeder Person. Bei einer vollen tippt ein Elternteil auf **Haben wir gemacht**. **Belohnung** unter einer Spalte fügt eine neue hinzu. Beides fragt zuerst **Wer bist du?**

> Note: Eine Tafel, die du mit **Tafel hier öffnen** oder **Wandmodus starten** unter deiner eigenen Anmeldung öffnest, zeigt nur an.
