Ein altes Tablet wird zum Familienbildschirm: **Start**, **Woche**, **Monat**, **Personen**, **Mahlzeiten**, **Listen**, **Gewohnheiten** und **Countdown**. In den Ruhezeiten des Elternteils, das ihn verbunden hat, wird er dunkler und zeigt **Nacht**.

1. Öffne auf dem Tablet app.daili.app/board/pair. Ein Code und ein QR-Code erscheinen.
2. In der App: **Einstellungen** → **Wandbildschirm** → **Bildschirm verbinden** (nur Admins). Gib den Code ein oder tippe auf **QR-Code scannen**. Am Computer gibst du den Code unter dieser Adresse ein.
3. Tippe auf **Bestätigen**.

Ein Computer als Bildschirm: dein Name → **Präferenzen** → **Diesen Browser als Familienbildschirm nutzen**.

> Note: Er zeigt nie Privates, auch nicht deins, und weder Notizen, Budget, Zyklus noch Dokumente.

Zum Entfernen: **Familie** oder **Wandbildschirm** → **Wandbildschirme** → **Entfernen**. Er stoppt auch, wenn dieses Elternteil die Familie verlässt oder kein Admin mehr ist. Am Tablet: **Zum Verlassen gedrückt halten**, dann **Nicht mehr nutzen**.

iPad: Zum Home-Bildschirm, öffnen und auf **Familienbildschirm einrichten** tippen. Automatische Sperre: Nie. Android: Chrome → App installieren.
