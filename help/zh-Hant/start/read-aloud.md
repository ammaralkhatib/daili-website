daili 可以用你手機內建的聲音，把你的一天唸給你聽。什麼都不會傳送出去。

![首頁上 + 旁邊有一張說話的臉，就是朗讀按鈕。朗讀按鈕被圈起來。](home-read-aloud)

1. 在首頁上，點 **+** 旁邊那張說話的臉。你會聽到**今天**裡顯示的內容：行程、待辦、習慣、購物、餐點和生日。
2. 再點一次就停止。離開首頁也會停止。
3. 按住它可以打開它的設定。

在**設定** → **朗讀**裡，選好**語速**和**語音**，再點**試聽**。關掉**在首頁顯示按鈕**就能隱藏這個按鈕。

![朗讀設定，有在首頁顯示按鈕、語速和語音。「在首頁顯示按鈕」開關被圈起來。](settings-read-aloud)

聽起來像機器人？免費換一個更好聽的聲音。iPhone：打開**設定** App → **輔助使用** → **Read & Speak** → **聲音** → 你的語言 → **聲音**。連上 Wi-Fi，下載一個標示**(premium)**或**(enhanced)**的聲音。Android：首頁或這些設定裡出現**教我怎麼做**時，點它，再點**安裝語音**，然後下載你的語言。daili 會自動使用新聲音。
