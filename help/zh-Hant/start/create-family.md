登入後，daili 會請你建立一個家庭或群組，或是加入一個。

![新使用者看到的歡迎畫面。「建立家庭或群組」按鈕被圈起來。](start-create-family)

1. 點**建立家庭或群組**。
2. 在**家庭或群組名稱**輸入名字，例如「陳家」或「足球隊」。
3. 選一個**顏色**。
4. 點**建立**。daili 會打開你的新首頁。

現在你就是擁有者了。接著邀請其他人，大家就會看到同樣的安排。

> Note: 家裡已經有人建立家庭了？那就不要再建第二個。點**加入家庭或群組**，用他們的邀請碼加入。
