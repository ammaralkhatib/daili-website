登入後，daili 會請你建立一個家庭或群組，或是加入一個。

![新使用者看到的歡迎畫面。「建立家庭或群組」按鈕被圈起來。](start-create-family)

1. 點**建立家庭或群組**。
2. 在**家庭或群組名稱**輸入名字，例如「陳家」或「足球隊」。
3. 選一個**顏色**。
4. 點**建立**。

這是你的第一個家庭？daili 會問：**你想用 Daili 做什麼？** 選好首頁要顯示的內容，點**繼續**，或點**略過**。

現在你就是擁有者了。邀請畫面會打開一次，你可以邀請其他人，或點**稍後**。

一週從你所在國家習慣的那一天開始，並顯示當地的國定假日。兩者都可以在**行事曆** → 齒輪 → **每週開始於**和**國定假日**裡修改。

新帳號？前面還有一步：**嗨！你是誰？** 選好你的大頭貼，確認你的名字。點**繼續**，或**略過**。

![「嗨！你是誰？」這一步，已選好大頭貼並填好名字。](start-you-step)

> Note: 家裡已經有人建立家庭了？那就不要再建第二個。點**加入家庭或群組**，用他們的邀請碼加入。
