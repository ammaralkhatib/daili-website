你可以決定首頁要顯示哪些卡片，以及它們的順序。每個卡片都能移動或隱藏，**筆記**也一樣。

![編輯模式下的首頁，每張卡片上都有一個 ×。右下角的「完成」按鈕被圈起來。](start-edit-home)

1. 在首頁上，按住任何一張卡片，直到卡片開始晃動。也可以點首頁最後那張虛線框的**編輯首頁**卡片。
2. 把卡片拖到新的位置。
3. 點卡片上的 **×** 就能隱藏它。點 **+** 就能把隱藏的卡片加回來。
4. 點右下角的**完成**。

![首頁的最後：「家庭」卡片後面是虛線框的「編輯首頁」卡片，它被圈起來。](start-edit-home-tile)

你也可以在**設定**的**首頁**裡做同樣的事：打開或關閉卡片，按住把手拖曳排序。

你第一次建立或加入家庭後選的功能，設定的也是這些卡片。**家庭**卡片預設在最後，除非你移動它。

> Note: 版面只會存在這支手機上。家裡每個人都自己設定自己的首頁。
