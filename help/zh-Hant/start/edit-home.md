你可以決定首頁要顯示哪些卡片，以及它們的順序。

![編輯模式下的首頁，每張卡片上都有一個 ×。右下角的「完成」按鈕被圈起來。](start-edit-home)

1. 在首頁上，按住任何一張卡片，直到卡片開始晃動。
2. 把卡片拖到新的位置。
3. 點卡片上的 **×** 就能隱藏它。點 **+** 就能把隱藏的卡片加回來。
4. 點右下角的**完成**。

你也可以在**設定**的**首頁**裡做同樣的事：打開或關閉卡片，按住把手拖曳排序。

> Note: 版面只會存在這支手機上。家裡每個人都自己設定自己的首頁。
