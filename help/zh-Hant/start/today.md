「今天」會在同一個畫面上顯示全家今天的安排。

![首頁的最上方。鈴鐺旁邊的「今天」按鈕被圈起來。](start-today)

1. 在首頁上，點右上角鈴鐺旁邊的**今天**。
2. 往下滑，看看**待辦**、**購物**和**今天吃什麼**等區塊。
3. 點區塊下面的連結，例如**行事曆**或**所有待辦**，就能打開完整的畫面。
4. 返回就會回到首頁。

沒有內容的區塊會隱藏起來。沒有安排的日子，你會看到**今天沒有安排**。
