生理週期預設關閉，要你自己打開，而且免費。家裡其他人看不到你的生理週期，也不知道你在用它。

1. 在首頁或**設定**裡點**生理週期**，再點**開始**。
2. 選上次月經開始的那天，再選你平常的天數。
3. 月經來了就點**月經來了**。要標記更早的日子，點**更早開始？**。
4. 月經期間，點**少**、**中**或**多**。點**症狀和心情**可以打開這一天。
5. 結束了？點**已經結束**，選最後一天。中間的日子也會算進去。

![生理週期卡片顯示第 18 天，有一圈圓點、「下次月經大約 11月23日 – 11月27日」和「月經來了」按鈕。下方月曆中今天被圈起來。](cycle-start)

在你點**已經結束**之前，生理週期會依你平常的經期天數來算。下次月經會顯示為一段日期範圍，不會是確切的某一天。

不需要？在**開始**下面點**不需要 — 隱藏生理週期**。在**設定** → **首頁**裡可以把這張卡片加回來。

> Note: 僅供參考。生理週期不是醫療器材，也不能用於避孕。詳情請見 daili.app 上的使用條款。
