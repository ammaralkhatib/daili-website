Uma tarefa que se repete é uma tarefa que volta. Quando você marca, ela passa para o próximo prazo.

![A janela Editar o item de uma tarefa. As opções de Repetir, Nunca, Todo dia, A cada poucos dias, Toda semana e Todo mês, estão circuladas.](lists-repeating)

1. Abra uma lista de tarefas e toque na tarefa.
2. Dê um **Prazo** a ela.
3. Em **Repetir**, escolha **Todo dia**, **A cada poucos dias**, **Toda semana** ou **Todo mês**.
4. Em **Toda semana**, escolha os dias em **Nestes dias**. Em **Todo mês**, escolha o **Dia do mês**.
5. Toque em **Salvar**.

Quando você marca a tarefa, uma mensagem diz quando ela volta.

> Note: **Repetir** fica cinza até a tarefa ter um prazo. Uma tarefa que se repete precisa de um prazo para avançar a partir dele.
