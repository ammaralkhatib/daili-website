Uma tarefa que se repete é uma tarefa que volta. Quando você marca, ela passa para o próximo prazo.

![A janela Editar o item de uma tarefa com todas as opções de Repetir. A cada poucas semanas está escolhido, a cada 2 semanas na quarta-feira. As opções de Repetir estão circuladas.](lists-repeating)

1. Abra uma lista de tarefas e toque na tarefa.
2. Dê um **Prazo** a ela.
3. Em **Repetir**, escolha **Todo dia**, **A cada poucos dias**, **Toda semana**, **A cada poucas semanas**, **Todo mês**, **A cada poucos meses** ou **Todo ano**.
4. Em **Toda semana**, escolha os dias em **Nestes dias**. Em **A cada poucas semanas**, escolha também quantas semanas.
5. Em **Todo mês**, escolha o **Dia do mês**. Em **A cada poucos meses**, escolha também quantos meses: 6 para repetir a cada meio ano.
6. Toque em **Salvar**.

A opção **Todo ano** volta todo ano no mesmo dia do prazo. Quando você marca uma tarefa, uma mensagem diz quando ela volta.

> Note: **Repetir** fica cinza até a tarefa ter um prazo. Uma tarefa que se repete precisa de um prazo para avançar a partir dele.
