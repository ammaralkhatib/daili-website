Xampu na lista do mercado? Mova para a lista certa.

![A janela Editar o item de Leite. A linha Mover para outra lista… está circulada.](lists-move-items)

1. Abra a lista e toque no item.
2. Toque em **Mover para outra lista…**.
3. Escolha a outra lista. O item vai para lá, e uma mensagem diz para onde ele foi.
4. Lista errada? Toque em **Desfazer** nessa mensagem.

> Note: **Mover para outra lista…** só aparece quando sua família tem outra lista do mesmo tipo. Itens de compras vão para listas de compras, e tarefas para listas de tarefas.
