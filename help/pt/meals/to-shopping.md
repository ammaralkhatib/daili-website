Chega de copiar ingredientes à mão.

![Uma receita com os ingredientes. O botão do carrinho de compras, lá em cima, está circulado.](meals-to-shopping)

1. Abra uma receita e toque no botão do carrinho de compras, lá em cima. Ou, no **Cardápio**, toque em **Compras**, embaixo, para levar a semana inteira.
2. Em **Adicionar em**, escolha a lista de compras.
3. Desmarque o que você já tem em casa.
4. Toque no botão embaixo, como **Adicionar 3 itens**.

Toque em **Abrir a lista** na mensagem para ver os itens.

**Adicionar tudo à lista**, embaixo dos ingredientes de uma receita, faz o mesmo. Se você mudou as porções, as novas quantidades vão para a lista.

No **Cardápio**, as quantidades seguem as **Porções** de cada refeição. Uma receita para 4 planejada para 8 mostra "para 8" e as quantidades dobram. Uma linha sem quantidade ganha "2×".

![Adicionar à lista de compras para esta semana. Curry de legumes mostra Jantar · qua., 18 de nov. · para 8 e as quantidades dobradas. A linha para 8 está circulada.](meals-week-shopping)

> Note: No cardápio, só as refeições feitas a partir de uma receita trazem ingredientes. As refeições sem receita não têm nenhum.
