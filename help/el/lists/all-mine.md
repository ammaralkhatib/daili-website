Σε μια πολυάσχολη οικογένεια βοηθά να βλέπεις μόνο τις δικές σου εργασίες.

![Το πάνω μέρος της οθόνης Εργασίες. Ο κύκλος της οικογένειας και η δική σου εικόνα πάνω δεξιά είναι κυκλωμένα.](lists-all-mine)

1. Στην αρχική οθόνη, πάτησε **Εργασίες**.
2. Στο πάνω μέρος, πάτησε τη δική σου εικόνα στα δεξιά. Αυτό είναι το **Δικά μου**: κάθε εργασία που σου έχει ανατεθεί, από όλες τις λίστες.
3. Πάτησε τον κύκλο της οικογένειας δίπλα για να δεις ξανά **Όλα**.
4. Μέσα σε μια λίστα εργασιών, οι κύκλοι στο πάνω μέρος δείχνουν την πρόοδο του καθενός. Πάτησε έναν για να δεις μόνο τις εργασίες του. Πάτησέ τον ξανά για να δεις όλων.

> Note: Μια εργασία ανήκει στα άτομα στα οποία έχει ανατεθεί. Αν δεν την έχει κανείς, ανήκει σε όποιον την πρόσθεσε.
