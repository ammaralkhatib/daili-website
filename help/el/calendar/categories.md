Το χρώμα ενός γεγονότος προέρχεται από την κατηγορία του. Έτσι ο «Αθλητισμός» μοιάζει ίδιος παντού. Κάθε οικογένεια ξεκινά με έξι: Οικογένεια, Δουλειά, Σχολείο, Αθλητισμός, Υγεία και Ελεύθερος χρόνος.

![Η οθόνη Κατηγορίες γεγονότων με έξι κατηγορίες. Η γραμμή Προσθήκη κατηγορίας είναι κυκλωμένη.](calendar-categories)

1. Στην αρχική οθόνη, πάτησε **Οικογένεια**.
2. Στην ενότητα **Ημερολόγιο**, πάτησε **Κατηγορίες γεγονότων**.
3. Πάτησε **Προσθήκη κατηγορίας**, γράψε ένα **Όνομα**, διάλεξε **Χρώμα** και πάτησε **Προσθήκη**.
4. Πάτησε μια κατηγορία για να τη μετονομάσεις ή να αλλάξεις το χρώμα της. Πάτησε **⋮** για να τη διαγράψεις.

Για να δώσεις κατηγορία σε ένα γεγονός, πάτησε **Κατηγορία** μέσα στο γεγονός. Στο **Ημερολόγιο**, πάτησε **Φίλτρο** για να δεις μόνο μία κατηγορία.

> Note: Οι κατηγορίες είναι κοινές για όλη την οικογένεια και όλοι μπορούν να τις αλλάξουν. Μια οικογένεια μπορεί να έχει έως 30.
