Η οικογένειά σου μπορεί να έχει τη δική της λίστα συνηθειών: κατηγορίες που ονομάζετε εσείς και συνήθειες που αποθηκεύσατε για να τις ξεκινάτε ξανά.

1. Στις **Συνήθειες**, πάτησε **+**.
2. Στο **Ξεκίνα μια συνήθεια**, πάτησε το κουμπάκι **Επεξεργασία** στη σειρά με τις κατηγορίες.
3. Στην ενότητα **Οι κατηγορίες της οικογένειάς σου**, γράψε ένα όνομα και πάτησε +. Με τα κουμπιά τη μετονομάζεις, τη μετακινείς ή τη διαγράφεις.
4. Στην ενότητα **Οι κατηγορίες του Daili**, πάτησε το μάτι για να κρύψεις όποια δεν χρειάζεσαι.

![Η οθόνη Κατηγορίες με την κατηγορία Πρωινή ρουτίνα. Το πεδίο Νέα κατηγορία είναι κυκλωμένο.](habits-categories)

Για να αποθηκεύσεις μια συνήθεια, άνοιξε το **Αποθήκευση στη λίστα συνηθειών μου** στη φόρμα της και διάλεξε **Κατηγορία**. Μετά εμφανίζεται στο **Ξεκίνα μια συνήθεια**. Κράτα την πατημένη εκεί για **Επεξεργασία**, **Μετακίνηση σε κατηγορία** ή **Διαγραφή**.

> Note: Όλη η οικογένειά σου τα βλέπει αυτά. Όποιος τα έφτιαξε, ή ένας διαχειριστής, μπορεί να τα αλλάξει. Μόνο οι διαχειριστές μπορούν να κρύψουν τις κατηγορίες του daili.
