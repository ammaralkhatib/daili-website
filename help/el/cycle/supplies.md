Λίγες μέρες πριν μπορεί να ξεκινήσει η επόμενη περίοδός σου, η οθόνη του Κύκλου μπορεί να ρωτήσει: «Η περίοδός σου μπορεί να ξεκινήσει σύντομα. Χρειάζεσαι κάτι;»

1. Πάτησε **Προσθήκη σε λίστα**.
2. Τσέκαρε ό,τι χρειάζεσαι ή γράψε κάτι δικό σου.
3. Στο **Αποθήκευση σε**, διάλεξε μία από τις ιδιωτικές σου λίστες αγορών ή **Νέα ιδιωτική λίστα**.
4. Πάτησε **Αποθήκευση**.

![Η οθόνη Προμήθειες με τσεκαρισμένα τα Σερβιέτες και Παυσίπονα και επιλεγμένη τη Νέα ιδιωτική λίστα. Η Αποθήκευση είναι κυκλωμένη.](cycle-supplies)

Προστίθενται μόνο όσα τσέκαρες, σε μια λίστα που βλέπεις μόνο εσύ.

Πάτησε × στην κάρτα για να την κρύψεις μέχρι την επόμενη φορά. Για να σταματήσει, κλείσε την **Πρόταση προμηθειών πριν την περίοδο** στις **Ρυθμίσεις κύκλου**.
