Μπορείς να αλλάξεις ποια πλακίδια δείχνει η αρχική οθόνη και με ποια σειρά. Κάθε πλακίδιο μετακινείται ή κρύβεται, και οι **Σημειώσεις**.

![Η αρχική οθόνη σε λειτουργία επεξεργασίας, με ένα × σε κάθε πλακίδιο. Το κουμπί Τέλος κάτω δεξιά είναι κυκλωμένο.](start-edit-home)

1. Στην αρχική οθόνη, κράτα πατημένο οποιοδήποτε πλακίδιο μέχρι τα πλακίδια να αρχίσουν να κουνιούνται.
2. Σύρε ένα πλακίδιο σε νέα θέση.
3. Πάτησε **×** σε ένα πλακίδιο για να το κρύψεις. Πάτησε **+** για να φέρεις πίσω ένα κρυμμένο πλακίδιο.
4. Πάτησε **Τέλος** κάτω δεξιά.

Το ίδιο μπορείς να κάνεις στις **Ρυθμίσεις**, στην **Αρχική οθόνη**: άνοιξε ή κλείσε πλακίδια και σύρε τα από τη λαβή.

> Note: Η διάταξή σου αποθηκεύεται μόνο σε αυτό το κινητό. Ο καθένας στην οικογένεια στήνει τη δική του αρχική οθόνη.
