In Paprika, esporta un file .paprikarecipes (formato Paprika) e salvalo sul tuo dispositivo, per esempio in File. I nomi dei menu possono cambiare.

1. Nella schermata iniziale, tocca **Ricette**, poi **+**, poi **Da un'altra app**, e scegli il file.
2. Togli la spunta da quello che non vuoi. Le ricette già presenti in daili partono senza spunta.
3. Tocca **Importa 12 ricette** (il numero di ricette spuntate). Non chiudere daili finché non ha finito.
4. Tocca **Vai alle ricette**.

Titolo, ingredienti, passaggi, porzioni, tempi, link della fonte, note e foto vengono importati. Le categorie diventano etichette.

> Note: Una famiglia può avere 50 etichette; le categorie in più non vengono aggiunte. Le ricette molto lunghe vengono accorciate (100 ingredienti, 50 passaggi). Il riepilogo finale te lo dice.

> Note: Il file viene letto sul tuo dispositivo; vengono salvate solo le ricette importate.

Mancano delle foto dopo **Interrompi** o senza internet? Importa di nuovo lo stesso file più tardi. daili le aggiunge e salta le ricette che hai già.

Solo file di Paprika, e non su app.daili.app.
