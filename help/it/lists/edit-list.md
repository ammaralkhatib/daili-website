Questi passaggi valgono sia per le liste della spesa sia per le liste di attività.

![La schermata Spesa con il menu ⋯ di una lista aperto. Modifica è cerchiato, con Elimina sotto.](lists-edit-list)

1. Nella schermata iniziale, tocca **Spesa** o **Attività**.
2. Sulla scheda della lista, tocca **⋯**, poi **Modifica**.
3. Cambia il **Nome**, il **Colore** o l'**Icona**, e tocca **Salva**.
4. Per cambiare l'ordine, tieni premuta una scheda, poi trascinala al suo nuovo posto.
5. Per eliminare una lista, tocca **⋯** sulla sua scheda, poi **Elimina**. Hai cambiato idea? Tocca **Annulla** nel messaggio.

> Note: Una lista eliminata sparisce per tutta la famiglia, con tutti i suoi elementi. **Annulla** funziona solo per pochi secondi.
