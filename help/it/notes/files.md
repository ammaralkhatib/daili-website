1. Apri **Impostazioni** → **Note** → **Immagini e registrazioni**.
2. Scegli **Su questo telefono** o **Cloud Daili**.

![Immagini e registrazioni, con Su questo telefono scelto e Cloud Daili sotto.](notes-files)

**Su questo telefono** è gratis e scelto di base. I file sono solo su questo telefono, e nel suo backup su iPhone. Gli altri vedono invece una piccola targhetta.

**Cloud Daili** fa parte di Daili Plus: 5 GB per famiglia. Tutti quelli con cui la nota è condivisa vedono i file, su ogni dispositivo.

Se condividi una nota con file solo sul telefono, daili chiede: **Condividi solo il testo** o **Sposta le foto nel cloud**. Un file in attesa di caricamento mostra un badge a forma di nuvola. Toccalo per riprovare.

Quando Plus finisce, non si elimina niente: i file nel cloud restano lì, quelli nuovi restano sul telefono (**Cloud Daili (in pausa)**).

Un disegno si può modificare solo sul telefono su cui è stato fatto. Un disegno nel cloud ha bisogno di una connessione.

> Note: Su Android, le immagini e le registrazioni delle note non sono nel backup del telefono. Il Cloud Daili le tiene al sicuro.
