Hai ricevuto un file di calendario (.ics) dalla scuola o da un club? daili ne copia gli eventi una volta nel calendario della famiglia.

1. Apri **Calendario** e tocca il pulsante delle impostazioni (l'ingranaggio) in alto a destra.
2. Sotto **Altri calendari**, tocca **Aggiungi un calendario**, poi **Importa un file (.ics)**, e scegli il file.
3. In **Importa file calendario**, togli la spunta da ciò che non vuoi. Tocca una data o un'ora per cambiarla.
4. Tocca il pulsante per aggiungere in basso.

![Il foglio Aggiungi un calendario nelle impostazioni del calendario. Importa un file (.ics) è cerchiato.](calendar-other-calendars)

Oppure parti dal file in Mail, File o nei download: condividilo con daili, oppure su Android aprilo con daili.

Gli eventi passati e le attività completate restano fuori. Le voci che hai già partono senza spunta. Alcune regole di ripetizione non si possono copiare, quindi quegli eventi vengono aggiunti una volta sola. Le attività finiscono nella lista che scegli sotto **Aggiungi a**.

> Note: Il file viene letto su questo telefono e non viene caricato. L'importazione funziona nell'app del telefono, non sul web.
