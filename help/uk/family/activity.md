Будь-хто може змінити спільну подію чи список. Список активності показує, хто це зробив.

![Список активності з рядками Список заархівовано і Список відновлено. Кнопку Очистити обведено.](family-activity)

1. На головному екрані натисни дзвіночок угорі праворуч. Число на ньому означає, що є щось нове.
2. Прогорни список. Зміни згруповано за **Сьогодні**, **Вчора** і давнішими датами.
3. Натисни зміну, щоб відкрити подію, список чи рецепт, якого вона стосується.
4. Щоб спорожнити список, натисни **Очистити** угорі й підтверди.

Кнопка **Очистити** спорожняє список лише для тебе. Твоя родина й далі бачить усе. Записи однаково зникають через 90 днів.

Нові зміни мають світлий фон, коли ти бачиш їх уперше. Коли хтось ділиться нотаткою з усією родиною, тут з’являється **Нотатку поділено**, без сповіщення. Якщо список заархівували чи відновили, тут це теж видно.
