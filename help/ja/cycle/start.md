生理周期はオンにするまでオフで、無料です。あなたの生理周期も、使っていることも、家族には見えません。

1. **設定**を開き、**生理周期**、**はじめる**の順にタップします。
2. 前回の生理が始まった日（たとえば**昨日**）と、いつもの日数を選びます。わからないときは**わからない — Daili が記録から学びます**をタップします。
3. 生理が始まったら**生理が始まった**をタップします。もっと前の日に印を付けるときは**もっと前に始まった？**をタップします。
4. 生理中は、カードの**少なめ**、**普通**、**多め**をタップします。**症状と気分**でその日の記録をすべて開けます。
5. 終わったら**終わった**をタップし、最後の日を選びます。その間の日も生理として数えます。

![生理周期のカードに「18日目」、「次の生理は10月26日〜10月30日ごろ」、「生理が始まった」ボタン。下の月のカレンダーで今日が丸で囲まれています。](cycle-start)

終わったと記録するまでは、いつもの日数のあいだ生理中として数えます。次の生理は1日ではなく、日付の幅で表示されます。

> Note: あくまで予測です。生理周期は医療機器ではなく、避妊には使えません。詳しくはdaili.appの利用規約をご覧ください。
