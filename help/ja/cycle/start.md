生理周期はオンにするまでオフで、無料です。あなたの生理周期も、使っていることも、家族には見えません。

1. ホーム画面か**設定**で**生理周期**をタップし、**はじめる**をタップします。
2. 前回の生理が始まった日と、いつもの日数を選びます。
3. 生理が始まったら**生理が始まった**をタップします。もっと前の日に印を付けるときは**もっと前に始まった？**をタップします。
4. 生理中は、**少なめ**、**普通**、**多め**をタップします。**症状と気分**でその日の記録を開けます。
5. 終わったら**終わった**をタップし、最後の日を選びます。その間の日も生理として数えます。

![生理周期のカードに「18日目」、点のリング、「次の生理は11月23日〜11月27日ごろ」、「生理が始まった」ボタン。下の月のカレンダーで今日が丸で囲まれています。](cycle-start)

**終わった**をタップするまでは、いつもの生理の日数で数えます。次の生理は1日ではなく、日付の幅で表示されます。

使わない場合は、**はじめる**の下にある**使わない — 生理周期を非表示にする**をタップします。**設定** → **ホーム画面**でタイルを元に戻せます。

> Note: あくまで予測です。生理周期は医療機器ではなく、避妊には使えません。詳しくはdaili.appの利用規約をご覧ください。
