ログインすると、dailiが家族・グループをつくるか、参加するかをたずねます。

![初めての人に表示されるようこそ画面。「家族・グループをつくる」ボタンが丸で囲まれています。](start-create-family)

1. **家族・グループをつくる**をタップします。
2. **家族・グループの名前**に名前を入力します。たとえば「佐藤家」や「サッカーチーム」です。
3. **色**を選びます。
4. **つくる**をタップします。dailiが新しいホーム画面を開きます。

これであなたがオーナーです。次にほかの人を招待すれば、みんなが同じ予定を見られます。

> Note: 家族をもう誰かがつくっていますか？その場合は2つ目をつくらずに、**家族・グループに参加する**をタップして、その人のコードを使ってください。
