ログインすると、dailiが家族・グループをつくるか、参加するかをたずねます。

![初めての人に表示されるようこそ画面。「家族・グループをつくる」ボタンが丸で囲まれています。](start-create-family)

1. **家族・グループをつくる**をタップします。
2. **家族・グループの名前**に名前を入力します。たとえば「佐藤家」や「サッカーチーム」です。
3. **色**を選びます。
4. **つくる**をタップします。

はじめての家族ですか？dailiが**Dailiを何に使いたいですか？**とたずねます。ホーム画面に表示するものを選んで**続ける**をタップするか、**スキップ**をタップします。

これであなたがオーナーです。招待の画面が一度だけ開くので、ほかの人を招待するか、「**あとで**」をタップします。

週は、あなたの国でふつうの曜日から始まり、その国の祝日が表示されます。どちらも**カレンダー** → 歯車 → 「**週の始まり**」と「**祝日**」で変えられます。

新しいアカウントなら、その前にもう1ステップあります：**こんにちは！あなたは誰？** 自分の写真を選んで、名前を確認します。**続ける**をタップするか、**スキップ**します。

![「こんにちは！あなたは誰？」のステップ。写真が選ばれ、名前が入力されています。](start-you-step)

> Note: 家族をもう誰かがつくっていますか？その場合は2つ目をつくらずに、**家族・グループに参加する**をタップして、その人のコードを使ってください。
