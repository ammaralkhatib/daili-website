dailiは、スマホ自身の声であなたの1日を読み上げます。どこにも何も送られません。

![+の横に、話している顔の「読み上げ」ボタンがあるホーム画面。「読み上げ」ボタンが丸で囲まれています。](home-read-aloud)

1. ホーム画面で、**+**の横にある話している顔のボタンをタップします。**今日**に出ている予定、やること、習慣、買い物、食事、誕生日が聞こえます。
2. もう一度タップすると止まります。ホーム画面から離れても止まります。
3. 長押しすると設定が開きます。

**設定** → **読み上げ**で、**速度**と**音声**を選び、**サンプルを聞く**をタップします。ボタンを隠すには、**ホームにボタンを表示**をオフにします。

![「読み上げ」の設定。ホームにボタンを表示、速度、音声があります。「ホームにボタンを表示」のスイッチが丸で囲まれています。](settings-read-aloud)

機械っぽい声ですか？もっと自然な声を無料で入れられます。iPhone：**設定**アプリ → **アクセシビリティ** → **Read & Speak** → **声** → 自分の言語 → **声**。Wi-Fiで、**（プレミアム）**か**（拡張）**と付いた声をダウンロードします。Android：ホーム画面かこの設定に**方法を見る**が出たらタップし、**音声をインストール**をタップして、自分の言語をダウンロードします。dailiは新しい声を自動で使います。
