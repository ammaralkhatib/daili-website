「今日」画面には、家族の今日の予定が1つの画面にまとまっています。

![「今日」画面。いちばん上の天気カードが丸で囲まれています。](start-today)

1. ホーム画面で、右上の天気とベルの間にあるカレンダーのアイコンをタップします。
2. **やること**、**買い物**、**今日の献立**などのセクションをスクロールして見ます。
3. セクションの下にある**カレンダー**や**すべてのやること**などのリンクをタップすると、その画面全体が開きます。
4. 戻るとホーム画面に戻ります。

天気がオンのときは、天気カードがいちばん上に表示されます。下に引っぱると更新され、タップすると**天気**画面が開きます。

**今日の献立**では、**今夜**に今夜の夕食が表示されます。レシピがあれば**レシピ**も付きます。まだ計画していませんか？よく食べる3つの料理から1つをタップして計画するか、**1週間を計画**をタップします。

何もないセクションは表示されません。何もない日は**今日は何もありません**と表示されます。
