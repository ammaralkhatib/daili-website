「今日」画面には、家族の今日の予定が1つの画面にまとまっています。

![ホーム画面の上部。ベルの横にある「今日」ボタンが丸で囲まれています。](start-today)

1. ホーム画面で、右上のベルの横にある**今日**をタップします。
2. **やること**、**買い物**、**今日の献立**などのセクションをスクロールして見ます。
3. セクションの下にある**カレンダー**や**すべてのやること**などのリンクをタップすると、その画面全体が開きます。
4. 戻るとホーム画面に戻ります。

何もないセクションは表示されません。何もない日は**今日は何もありません**と表示されます。
