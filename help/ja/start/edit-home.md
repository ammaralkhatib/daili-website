ホーム画面に表示するタイルと、その順番を変えられます。**メモ**を含め、どのタイルも移動したり隠したりできます。

![編集モードのホーム画面。各タイルに×が付いています。右下の「完了」ボタンが丸で囲まれています。](start-edit-home)

1. ホーム画面で、タイルが揺れはじめるまでどれかのタイルを長押しします。または、ホーム画面のいちばん最後にある点線の**ホームを編集**タイルをタップします。
2. タイルを新しい場所へドラッグします。
3. タイルの**×**をタップすると隠れます。**+**をタップすると、隠したタイルが戻ります。
4. 右下の**完了**をタップします。

![ホーム画面のいちばん最後。「家族」タイルの次に、点線の「ホームを編集」タイルがあり、丸で囲まれています。](start-edit-home-tile)

**設定**の**ホーム画面**でも同じことができます。タイルをオン・オフにして、つまみの部分をドラッグします。

はじめての家族をつくったり参加したりしたあとに選んだ機能も、これと同じタイルの設定です。**家族**タイルは、動かさないかぎりいちばん最後にあります。

> Note: 並び順はこのスマホにだけ保存されます。家族はそれぞれ自分のホーム画面を設定します。
