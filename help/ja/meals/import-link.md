ネットでいいレシピを見つけましたか？書き写さずに保存しましょう。

![+メニューが開いた「レシピ」画面。「リンクから取り込む」が丸で囲まれています。](meals-import-link)

1. レシピページのリンクをコピーします。
2. ホーム画面で**レシピ**、**+**、**リンクから取り込む**の順にタップします。
3. **レシピのリンク**にリンクを貼り付けるか、**貼り付け**をタップします。そして**取り込む**をタップします。
4. dailiが読み取った内容を確認して、おかしなところを直します。そして**保存**をタップします。

ページにレシピのデータがない場合でも、dailiはタイトルと写真を保存します。材料と手順は自分で追加してください。

> Note: InstagramとTikTokのリンクにはレシピのデータがありません。代わりにレシピの文章をコピーして、**レシピの文章を貼り付ける**を使ってください。YouTubeの場合は**YouTube動画から**を使ってください。
