Paprikaで.paprikarecipesファイル（Paprika形式）をエクスポートして、端末に保存します。たとえば「ファイル」アプリです。メニューの名前は違うことがあります。

1. ホーム画面で**レシピ**、**+**、**ほかのアプリから**の順にタップして、ファイルを選びます。
2. いらないレシピのチェックを外します。すでにdailiにあるレシピは、最初からチェックが外れています。
3. **12 件のレシピを取り込む**をタップします（数はチェックしたレシピの数です）。終わるまでdailiを開いたままにしてください。
4. **レシピへ**をタップします。

タイトル、材料、手順、人数、時間、元のリンク、メモ、写真が取り込まれます。カテゴリはタグになります。

> Note: 1つの家族で使えるタグは50個までです。それを超えるカテゴリは追加されません。長いレシピは短くなります（材料100個、手順50個まで）。最後のまとめ画面でお知らせします。

> Note: ファイルはお使いの端末の中で読み込まれます。保存されるのは、取り込んだレシピだけです。

**中止**したあとや、インターネットにつながっていないときに、写真が入らなかったですか？あとで同じファイルをもう一度取り込んでください。dailiが写真を追加し、すでにあるレシピはスキップします。

使えるのはPaprikaのファイルだけです。app.daili.appでは使えません。
