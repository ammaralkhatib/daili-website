Tangan penuh tepung? Mode memasak menjaga layar tetap terang.

![Resep dengan tombol Mode memasak di atas bahan. Tombolnya dilingkari.](meals-cook-mode)

1. Buka resep.
2. Nyalakan **Mode memasak**, di atas bahan-bahan.

Sekarang layar tetap menyala selama resepnya terbuka.

Mode memasak mati setiap kali Anda membuka resep. Mode ini mati sendiri setelah 1 jam tanpa sentuhan.
