Simpan dokumen asuransi, surat sekolah, dan struk dalam folder.

![Dokumen dengan kartu folder dan baris privasi di bawahnya. Tombol ⋮ di folder pertama dilingkari.](vault-documents)

1. Di Beranda, ketuk **Dokumen**, lalu ketuk sebuah folder.
2. Untuk folder baru, ketuk tombol folder di kanan bawah (**Folder baru**). Ketik **Nama folder**, pilih **Warna**, lalu ketuk **Simpan**.
3. Di dalam folder, ketuk **+** dan pilih **Berkas**, **Dari galeri foto**, atau **Ambil foto**.
4. Ketuk berkas untuk membukanya. Ketuk **⋮** di sebelahnya untuk **Ganti nama**, **Pindahkan**, **Bagikan**, atau **Hapus**.
5. Untuk mengubah atau menghapus folder, ketuk **⋮** di folder itu, lalu **Edit** atau **Hapus**.

Kalau Anda ada di dua keluarga atau grup atau lebih, **Tampilkan di** memilih **Semua keluarga saya** atau satu keluarga. Label kecil menandai folder yang hanya tampil di keluarga ini.

**Bagikan** mengirim salinan ke aplikasi lain, seperti email atau aplikasi pesan. daili menyimpan salinannya sendiri, jadi menghapus yang satu tidak pernah menghapus yang lain.

> Note: Menghapus folder juga menghapus berkas di dalamnya. Ini tidak bisa dibatalkan.
