Simpan dokumen asuransi, surat sekolah, dan struk dalam folder, langsung di daili.

![Folder Dokumen penting dengan tiga berkas. Tombol + di kanan bawah dilingkari.](vault-documents)

1. Di Beranda, ketuk **Dokumen**, lalu ketuk sebuah folder.
2. Untuk folder baru, ketuk tombol folder di kanan bawah (**Folder baru**). Ketik **Nama folder**, pilih **Warna**, lalu ketuk **Simpan**.
3. Di dalam folder, ketuk **+** dan pilih **Berkas**, **Dari galeri foto**, atau **Ambil foto**.
4. Ketuk berkas untuk membukanya. Ketuk **⋮** di sebelahnya untuk **Ganti nama**, **Pindahkan**, **Bagikan**, atau **Hapus**.
5. Untuk mengganti nama atau menghapus folder, tekan lama folder itu.

**Bagikan** mengirim salinan ke aplikasi lain, seperti email atau aplikasi pesan. Begitulah cara memberikan berkas ke anggota keluarga.

daili menyimpan salinannya sendiri untuk tiap berkas. Menghapusnya di sini tidak menghapus aslinya di ponsel, dan menghapus aslinya tidak menghapusnya di sini.

> Note: Menghapus folder juga menghapus berkas di dalamnya. Ini tidak bisa dibatalkan.
