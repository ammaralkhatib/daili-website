Di Siklus, ketuk ikon roda gigi untuk **Pengaturan siklus**.

1. **Pengingat**: **Pengingat haid** datang beberapa hari sebelumnya. **Tanya apakah haid saya sudah mulai** menyala sejak awal dan bertanya sehari setelah rentang perkiraan. Layar kunci hanya menampilkan "Anda punya pengingat. Ketuk untuk membuka".
2. **Kunci Siklus**: meminta Face ID, sidik jari, atau kode ponsel Anda. Pengalih aplikasi selalu menyembunyikan Siklus, dan Android memblokir tangkapan layarnya.
3. **Tampilkan di kalender saya**: kalender di ponsel ini menampilkan tetesan, penuh kalau dicatat, garis tepi kalau perkiraan. Mati sejak awal; keluarga tidak pernah melihatnya.
4. **Impor (CSV)** memulihkan file dari **Ekspor (CSV)** dan tetap menyimpan hari yang sudah ada di sini.

![Pengaturan siklus dengan Tampilkan di kalender saya, tombol perlengkapan, serta Ekspor dan Impor. Kunci Siklus dilingkari.](cycle-settings)

Data Anda tetap di ponsel ini dan cadangannya, tidak pernah di server daili. Biarkan iCloud Backup atau cadangan Google tetap menyala.

> Note: Keluar dari akun menghentikan pengingat. Menghapus akun akan menghapus data di ponsel ini. Selengkapnya di kebijakan privasi di daili.app.
