Di Siklus, ketuk ikon roda gigi untuk **Pengaturan siklus**.

1. **Pengingat**: **Pengingat haid** datang beberapa hari sebelumnya. **Tanya apakah haid saya sudah mulai** bertanya sehari setelah rentang perkiraan. Layar kunci hanya bertuliskan "Anda punya pengingat. Ketuk untuk membuka".
2. **Privasi**: **Kunci Siklus** meminta Face ID, sidik jari, atau kode ponsel. Pengalih aplikasi menyembunyikan Siklus, dan Android memblokir tangkapan layarnya. **Tampilkan teks jelas di layar kunci** menampilkan pengingat lengkap.
3. Juga di **Privasi**, **Tampilkan di kalender saya**: kalender ponsel Anda menampilkan tetesan, penuh kalau dicatat, garis tepi kalau perkiraan. Keluarga tidak pernah melihatnya.
4. **Impor (CSV)** memulihkan file **Ekspor (CSV)**, dengan tetap menyimpan hari yang sudah ada di sini.

![Pengaturan siklus dengan lama siklus Anda yang biasa, Pengingat dengan tombol perlengkapan, dan bagian Privasi. Kunci Siklus dilingkari.](cycle-settings)

Data Anda tetap di ponsel ini dan cadangannya, tidak pernah di server daili. Biarkan iCloud Backup atau cadangan Google tetap menyala.

> Note: Keluar dari akun menghentikan pengingat. Menghapus akun akan menghapus data di ponsel ini. Selengkapnya di kebijakan privasi di daili.app.
