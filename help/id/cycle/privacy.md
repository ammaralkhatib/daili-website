Buka Siklus dan ketuk ikon roda gigi untuk **Pengaturan siklus**.

Di bawah **Pengingat**: **Pengingat haid** dengan **Hari sebelumnya**, **Pengingat mencatat**, dan **Waktu pengingat**. Di layar kunci, pengingat hanya berbunyi "Anda punya pengingat", kecuali Anda menyalakan **Tampilkan teks jelas di layar kunci**.

Nyalakan **Kunci Siklus**, maka Siklus meminta Face ID, sidik jari, atau kode ponsel Anda. Siklus terkunci lagi setelah ditinggal satu menit.

Data Siklus Anda hanya ada di ponsel ini dan di cadangan ponsel itu sendiri. Server daili tidak pernah menerimanya. **Ekspor (CSV)** menyimpan salinannya sebagai file. **Hapus semua data siklus** menghapusnya.

> Note: Keluar dari akun tetap menyimpan data Anda, tetapi pengingat berhenti. Menghapus akun akan menghapus data dari ponsel ini; cadangan ponsel yang lebih lama mungkin masih menyimpannya. Selengkapnya di kebijakan privasi di daili.app.
