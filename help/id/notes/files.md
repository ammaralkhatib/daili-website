1. Buka **Pengaturan** → **Catatan** → **Gambar dan rekaman**.
2. Pilih **Di ponsel ini** atau **Cloud Daili**.

![Gambar dan rekaman, dengan Di ponsel ini dipilih dan Cloud Daili di bawahnya.](notes-files)

**Di ponsel ini** gratis dan menjadi bawaan. File hanya ada di ponsel ini, dan di cadangannya di iPhone. Orang lain melihat chip kecil sebagai gantinya.

**Cloud Daili** termasuk dalam Daili Plus: 5 GB per keluarga. Semua orang yang menerima catatan itu melihat filenya, di setiap perangkat.

Saat membagikan catatan dengan file yang hanya ada di ponsel, Anda ditanya: **Bagikan teks saja** atau **Pindahkan foto ke cloud**. File yang menunggu diunggah menampilkan lencana awan. Ketuk untuk mencoba lagi.

Saat Plus berakhir, tidak ada yang dihapus: file di cloud tetap ada, file baru disimpan di ponsel (**Cloud Daili (dijeda)**).

Gambar tangan hanya bisa diedit di ponsel tempat gambar itu dibuat. Gambar tangan di cloud butuh koneksi.

> Note: Di Android, gambar dan rekaman catatan tidak ikut dalam cadangan ponsel. Cloud Daili menyimpannya dengan aman.
