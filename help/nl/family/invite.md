Iedereen in je gezin ziet dezelfde agenda, lijsten en verjaardagen.

1. Tik op het startscherm op **Gezin**. Je huidige code staat onder **Lid uitnodigen**.
2. Tik op **Lid uitnodigen**.
3. Deel de 6-cijferige code onder **Code**, laat de **QR-code** zien of tik op **Link delen**.
4. De ander opent daili, tikt op **Deelnemen aan gezin of groep** en typt de code of plakt de link, of tikt op **QR-code scannen**.

![Het gezinsscherm. Lid uitnodigen, met de huidige code en de einddatum eronder, is omcirkeld.](family-invite)

Net een gezin aangemaakt? Dan opent dit scherm één keer vanzelf, met **Kind zonder account toevoegen** en **Later**.

Elke code werkt voor één persoon. De code en de link werken al voordat je e-mailadres bevestigd is. Voor een uitnodiging per e-mail heb je hun adres en je eigen bevestigde e-mailadres nodig: tik daar op **E-mailadres bevestigen**. Apple blokkeert onze e-mails naar iCloud soms, dus stuur de code ook.

> Note: Een code werkt 7 dagen. Naar de verkeerde persoon gestuurd? Tik op **Leden uitnodigen** op **Nieuwe code maken**. Alle oudere codes werken dan niet meer; uitnodigingen per e-mail blijven geldig.
