Everyone in your family sees the same calendar, lists and birthdays.

1. On Home, tap **Family**. Your current code shows under **Invite member**.
2. Tap **Invite member**.
3. Share the 6-digit code from **Code**, show the **QR code**, or tap **Share link**.
4. They open daili, tap **Join a family or group** and type the code or paste the link, or tap **Scan QR code**.

![The Family screen. Invite member, with the current code and its end date under it, is circled.](family-invite)

Just created a family? This screen opens once by itself, with **Add a child without an account** and **Later**.

Each code works for one person. The code and link work before your email is verified. An email invite needs their address and your verified email: tap **Verify email** there. Apple sometimes blocks our emails to iCloud, so send the code too.

> Note: A code works for 7 days. Sent it to the wrong person? Tap **Get a new code** on **Invite members**. All older codes stop working; email invites stay.
