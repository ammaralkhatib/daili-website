# Privacy policy for app 1.14.0: language per device, family wall screens

## Why
App 1.14.0 (20) and the server behind it changed two things the privacy
policy must say. It must be true and **deployed before build 20 goes into
review**:
1. **Language per device** (api `9444ee7`, app `a4294f25`, web `d10494c`):
   every phone (and every browser with notifications on) now sends the
   language it shows Daili in when it registers for notifications. The server
   stores it on that device's row (`devices.locale`) and writes every
   notification for that device in that language. E-mails still use the
   account language (`users.locale`). The device language is in the data
   export.
2. **Family wall screens** (api `0c66db6` `650081e` `f3f77df`, web
   `61f1278` `0eebe9b` `6d5bf8d`, app `2026-10-29/001`): an admin can turn a
   tablet into a family wall screen on app.daili.app/board — on the tablet
   itself, or by approving a 6-digit code / QR the tablet shows (app or web).
   The server stores a screen row (family, the screen's name, display
   settings, when it was last used, when it was removed) and a key for that
   screen; the tablet's browser keeps the key. A wall screen only ever shows
   the family's SHARED things: never private events, lists, items, habits or
   private calendars, and never Notes, Budget, Documents/Photos, the activity
   list or connected accounts. Ticks made on the screen count for the person
   they belong to and show in the activity list as made "on the screen
   <name>". Pairing requests are deleted within a day. Removing the screen
   (Family → Wall screens, app or web) ends its key; so do leaving the
   family, losing the admin role or deleting the account.

The English and German texts below were written by Planning Claude against
the commits and reports. **Use them word for word.** Before you write, check
