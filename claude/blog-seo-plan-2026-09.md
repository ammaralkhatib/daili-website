## 1. Strategy

The obvious keywords — "best family calendar app", "family organisation apps",
"Cozi alternatives" — were checked against live search results in Sept 2026 and
are all held by 10–15 rival app blogs refreshed yearly, plus Cozi's own brand
page and the app stores. A zero-authority domain cannot enter that pile.

**Deliberately skipped:**
- Head terms and "best app" listicles — saturated.
- Co-parenting / custody calendar keywords — owned by OurFamilyWizard and
  TalkingParents, AND a product mismatch (daili has no custody schedule,
  expense log, or court-admissible message record). Traffic would bounce.
- "Family command center" — Pinterest + DIY decor blogs, wrong intent (physical
  pegboards, not software).
- Printable chore charts / meal plan templates — download intent, owned by mom
  blogs with deep Pinterest link equity.

**The bet: four narrow clusters, uncontested, all matching real daili features.**

| Cluster | Posts | Why |
|---|---|---|
| A — Family document vault | 6 | Every ranking page assumes paper + a fireproof box. The digital/on-device version is uncontested and is literally daili's vault. |
| B — Leaving Cozi | 4 | Nine sites rank "Cozi alternatives"; zero explain how to get the data out. Highest buyer intent in the niche. |
| C — Getting the family to use it | 5 | Every post assumes the family will use the app. The real failure is one adult who never opens it. Almost no supply. |
| D — Privacy, children's data, Europe | 3 | No competitor blog covers it. daili is EU-hosted with a GDPR export — a moat rivals cannot copy. |
| E — Mixed-device households | 2 | Head term is spam-farm owned; the natural phrasings are wide open. |

**Note:** familydaily.app's blog has not published since 2025-06-10 (20 posts,
15 months stale). The reference competitor is not defending its ground.

## 3. Rules every post follows

| Element | Rule |
|---|---|
| Title tag | 50–60 chars, primary keyword in the first half. |
| Meta description | 140–158 chars, written to earn the click, keyword once, naturally. |
| URL | `daili.app/blog/<slug>` — lowercase, hyphens, no dates. Never change a published slug. |
| H1 | Exactly one, close to but not identical to the title tag. |
| H2s | 5–8, each a natural keyword variant or a real question. |
| Length | 1,200–1,800 words. |
| First 100 words | Name the problem in the reader's words and state the answer. No warm-up. |
| FAQ block | 3–5 real questions with `FAQPage` JSON-LD. This wins the AI answer boxes. |
| Internal links | 2–4, descriptive anchors, always including the cluster pillar. |
| External links | 1–2 to a genuine authority (gov.uk, a vendor's own FAQ, a regulator). |
| Hero image | One Pexels photo, WebP, under 150 KB, descriptive alt text. |
| CTA | One soft mention at ~60%, one clear CTA at the end. Never open with a pitch. |
| Schema | `Article` + `FAQPage` on every post; `HowTo` where genuinely step-by-step. |
| After publishing | Submit in Search Console the same day; add the link from the pillar post. |
