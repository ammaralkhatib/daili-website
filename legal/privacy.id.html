2. Situs web ini

daili.app adalah situs statis. Situs ini tidak memasang cookie apa pun, tidak memakai alat analitik apa pun, dan tidak memuat font atau skrip pihak ketiga. Penyedia hosting kami otomatis menyimpan log server berumur pendek (alamat IP, waktu, halaman yang diminta) demi keamanan; kami tidak memakainya untuk hal lain. Dasar hukum: kepentingan sah kami atas situs yang aman (Pasal 6(1)(f) GDPR).

Selain memuat halamannya, situs ini tidak mengirim apa pun dengan sendirinya. Yang mengirim hanya dua hal opsional yang kamu pakai sendiri: formulir buletin dan masukan pusat bantuan di bawah. Satu-satunya formulir di situs ini adalah pendaftaran buletin di bawah tulisan blog kami: formulir itu mengirim alamat e-mail yang kamu ketik ke server kami sendiri (api.daili.app) dan tidak ada yang lain — lihat "Buletin (opsional)" di bagian 4.

Masukan pusat bantuan (opsional). Jika kamu mengetuk "Was this helpful?" di artikel bantuan, atau pencarian di pusat bantuan tidak menemukan apa pun, browser-mu mengirim hitungan anonim ke server kami sendiri (api.daili.app): artikel mana dan ya/tidak, atau teks pencariannya. Isinya tanpa nama, tanpa akun, tanpa cookie, dan tanpa ID perangkat. Kami tidak menyimpan alamat IP-mu bersamanya, hanya tanggalnya. Teks pencarian yang terlihat seperti alamat e-mail atau nomor telepon kami buang, dan semuanya kami hapus setelah 180 hari. Kami memakainya hanya untuk memperbaiki artikel bantuan. Dasar hukum: kepentingan sah kami atas halaman bantuan yang berguna (Pasal 6(1)(f) GDPR).

3. Aplikasi web (app.daili.app)

Daili juga berjalan di peramban, di app.daili.app. Aplikasi web tidak memasang cookie apa pun dan tidak memuat alat analitik apa pun (server kami hanya menghitung hari aktif — lihat "Seberapa sering kamu memakai Daili" di bagian 4). Font disajikan dari server kami sendiri, jadi saat dijalankan aplikasi web tidak memuat font atau skrip pihak ketiga.

Alih-alih cookie, peramban menyimpan token masukmu di penyimpanan lokal miliknya sendiri. Token itulah yang membuktikan kepada server kami bahwa sebuah permintaan berasal darimu, dan keluar dari akun akan menghapusnya. Di sampingnya, peramban menyimpan beberapa pengaturan tampilan agar aplikasi terlihat sama saat berikutnya dibuka: bahasa dan tema, tampilan kalender yang terakhir kamu pakai, kotak mana yang kamu tampilkan di layar utama, apakah bilah samping diciutkan, dan waktu pengingat bawaanmu. Pengaturan itu tetap di perangkatmu, tidak pernah dikirim kepada kami, dan bertahan sampai kamu menghapus data situs di peramban. Semua yang disimpan di sini bersifat mutlak diperlukan untuk masuk atau merupakan preferensi yang kamu pilih sendiri — karena itu tidak ada spanduk cookie.

Masuk dengan Google atau Apple (opsional). Hanya jika kamu memilih masuk lewat akun sosial, sebuah jendela terbuka melalui Firebase Authentication, persis seperti di aplikasi ponsel. Jika kamu masuk dengan alamat e-mail dan kata sandi, tidak ada kode Google atau Apple yang berjalan sama sekali.

Notifikasi peramban (opsional). Hanya jika kamu menyalakannya dan peramban memberi izin, aplikasi web mendaftarkan service worker dan mengambil token perangkat dari Firebase Cloud Messaging. Token itu beserta nomor perangkatnya lalu disimpan di penyimpanan lokal, dan salinan token masukmu disimpan di basis data peramban (IndexedDB) agar tombol pada sebuah notifikasi tetap bekerja ketika tidak ada tab Daili yang terbuka. Mematikan notifikasi, atau keluar dari akun, menghapus semuanya. Peramban juga mengirim bahasa yang dipakai aplikasi web, agar notifikasinya memakai bahasa itu.

Cuaca di aplikasi web (opsional). Jika kamu mencari kota untuk cuaca di aplikasi web, atau membiarkan peramban membagikan perkiraan lokasimu, server kami mencari tempat itu dengan Apple Maps (Maps Server API milik Apple). Server hanya mengirim teks pencarian, atau posisi yang dibulatkan sampai sekitar 1 km, beserta bahasamu — tidak pernah namamu atau akunmu. Server kami menyimpan hasilnya paling lama satu hari tanpa kaitan apa pun denganmu, supaya pencarian berikutnya lebih cepat. Seperti setiap permintaan, alamat permintaan (yang berisi teks pencarian atau posisi yang dibulatkan) muncul di log teknis server kami yang berumur pendek, yang kami simpan hanya demi keamanan. Prakiraan cuacanya sendiri bekerja seperti yang dijelaskan untuk aplikasi di bagian 4.

4. Data yang diproses aplikasi

Data akun. Saat kamu mendaftar, kami menyimpan nama tampilan, alamat e-mail, dan kata sandimu (hanya sebagai hash yang aman — kami tidak bisa membacanya). Opsional: foto profil. Kami juga menyimpan bahasamu: sampai kamu memilih bahasa di Pengaturan, aplikasi mengirim bahasa ponselmu, agar e-mail sampai kepadamu dalam bahasa yang kamu pahami. Dasar hukum: pelaksanaan kontrak denganmu (Pasal 6(1)(b) GDPR).

Masuk dengan Google atau Apple (opsional). Jika kamu memilih masuk lewat akun sosial, autentikasi berjalan melalui Firebase Authentication (Google Ireland Ltd.). Kami menerima namamu, alamat e-mail (Apple memungkinkanmu menyembunyikannya di balik alamat penerus), dan ID pengguna teknis. Kami tidak pernah melihat kata sandi Google atau Apple-mu.

Konten keluarga. Semua yang dibuat keluargamu di aplikasi disimpan di server kami agar anggota keluargamu bisa melihatnya: acara kalender dan pengingat, daftar belanja dan tugas, resep dan rencana makan, ulang tahun dan perayaan, alamat kalender eksternal yang dilanggan, serta profil anggota keluarga — termasuk profil terkelola untuk anak (nama, ulang tahun opsional, foto opsional) yang dibuat dan dikendalikan orang tua. Konten ini hanya terlihat oleh anggota keluargamu, tidak pernah oleh pengguna lain dan tidak pernah untuk umum. Jika kamu memilih pengingatmu sendiri untuk sebuah acara, kami menyimpan pilihan itu untukmu; hanya kamu yang melihatnya.

Hadiah kebiasaan (opsional). Sebuah keluarga bisa menetapkan hadiah untuk kebiasaannya. Kami menyimpan judul, ikon, dan warna hadiah, untuk siapa hadiah itu, berapa bintang yang dibutuhkan, kebiasaan mana yang dihitung, apakah hadiah itu dimulai lagi, berapa putaran yang sudah selesai, siapa yang membuatnya, kapan hadiah itu tercapai, serta siapa yang terakhir mengetuk "Sudah kami lakukan" dan kapan. Setiap anggota keluarga bisa melihat hadiah keluarga. Bintang dihitung dari centang kebiasaan yang sudah kami simpan; kebiasaan pribadi tidak menghasilkan bintang. Saat sebuah hadiah tercapai, anggota keluarga lainnya mendapat notifikasi push (sakelar: "Kabar kebiasaan") berisi judul hadiah dan nama seorang anggota keluarga, dan daftar Aktivitas keluarga menampilkan satu baris. Hadiah dari keluarga-keluargamu termasuk dalam ekspor datamu. Saat seseorang keluar dari keluarga, hadiah untuk orang itu dihapus; hadiah yang ia buat untuk orang lain tetap ada di keluarga. Menghapus keluarga akan menghapus semua hadiahnya. Dasar hukum: pelaksanaan kontrak denganmu (Pasal 6(1)(b) GDPR).

Daftar stok (opsional). Daftar stok mencatat barang-barang yang kamu punya di rumah. Saat seseorang menandai sebuah barang sebagai hampir habis atau habis, kami menyimpan kapan dan oleh siapa, dan semua orang yang bisa melihat daftar itu melihatnya. Jika di pengaturan daftar stok dipilih sebuah daftar belanja, barang itu lalu ditambahkan ke daftar belanja tersebut.

Keinginan makanan dan siapa yang ikut makan. Seorang anggota keluarga bisa mengajukan keinginan untuk sebuah makanan. Kami menyimpan apa yang diinginkan (teks bebas atau salah satu resep keluarga), catatan opsional, siapa yang mengajukannya dan, jika orang tua mengajukannya untuk anak, untuk anak yang mana; setelah keinginan itu direncanakan, juga siapa yang merencanakannya, kapan, dan menjadi menu makan yang mana. Semua orang di keluarga melihat keinginan-keinginan itu, dan daftar Aktivitas menampilkannya. Saat keinginanmu direncanakan, kamu mendapat notifikasi push (sakelar: "Keinginan makanan Anda") berisi keinginan, hari, dan menu makannya. Keinginan yang sudah direncanakan dihapus 30 hari setelah menu makannya; keinginan yang masih terbuka tetap ada sampai seseorang di keluarga menghapusnya, dan jika akunmu dihapus, keinginanmu tetap ada di keluarga tanpa namamu. Untuk setiap menu makan yang direncanakan, kami juga menyimpan siapa yang tidak ikut makan. Dasar hukum: pelaksanaan kontrak denganmu (Pasal 6(1)(b) GDPR).

Daftar belanja. Daftar belanja hanya menyimpan 60 barang terbaru yang sudah dibeli; saat kamu mencentang sebuah barang, barang lama yang sudah dibeli di luar 60 ini dihapus otomatis. Jika kamu menandai sebuah barang sebagai mendesak, tanda itu disimpan bersama barangnya, semua orang yang bisa melihat daftar itu melihatnya, dan tanda itu hilang saat barangnya dibeli. Jika kamu mengetuk "Saya mau belanja" di sebuah daftar, anggota keluarga lain yang punya akun mendapat satu notifikasi push berisi namamu dan nama daftar itu (sakelar: "Seseorang akan belanja"). Ini tidak pernah terjadi untuk daftar pribadi. Selain catatan singkat yang disimpan selama 30 menit agar notifikasi tidak terkirim dua kali, kami tidak menyimpan catatan apa pun tentang ketukan itu. Dasar hukum: pelaksanaan kontrak denganmu (Pasal 6(1)(b) GDPR).

Catatan dan reaksi resep. Sebuah resep bisa punya catatan dari keluargamu — satu catatan bersama, disimpan tanpa nama orang yang menulisnya. Setiap anggota keluarga bisa menyatakan seberapa suka mereka dengan sebuah resep ("Suka sekali" atau "Kurang suka"), dan orang tua dengan peran admin bisa melakukannya untuk anak. Kami menyimpan jawaban ini bersama resepnya, dan semua orang di keluarga bisa melihat siapa menjawab apa, juga di layar dinding keluarga. Seberapa sering sebuah resep direncanakan dihitung dari rencana makan; angka itu tidak disimpan tersendiri. Server kami membaca jumlah, satuan, dan judul dari baris-baris bahan dengan aturan tetap di server kami sendiri — tidak ada AI yang dipakai untuk ini. Kami juga menyimpan dari mana sebuah resep berasal (misalnya diketik, tautan, foto, atau saran AI). Catatan resep dan jawabanmu sendiri termasuk dalam ekspor datamu. Jawabanmu dihapus saat kamu keluar dari keluarga atau akunmu dihapus; catatannya tetap ada di resep keluarga. Menghapus keluarga akan menghapus resep, catatan, dan jawabannya. Dasar hukum: pelaksanaan kontrak denganmu (Pasal 6(1)(b) GDPR).

Kalender terhubung (opsional). Jika kamu menambahkan kalender ponselmu, acara-acara itu dibaca dan ditampilkan hanya di perangkatmu — tidak pernah diunggah ke server kami, dan keluargamu tidak bisa melihatnya — kecuali kamu sendiri menyalin salah satunya ke Daili (lihat "Edit di Daili" di bawah). Jika kamu menghubungkan kalender Google atau Outlook, Daili membaca kalender yang kamu pilih dan menyimpan acaranya di server kami agar kamu — dan, hanya jika kamu mau, keluargamu — bisa melihatnya di kalender keluarga. Daili hanya membaca kalender-kalender ini, kecuali kamu mengubah salah satu kalender Google atau Outlook-mu ke sinkronisasi "Dua arah". Sinkronisasi dua arah diluncurkan secara bertahap, jadi mungkin belum tersedia untukmu. Dengan fitur ini, kamu bisa menambah, mengubah, dan menghapus sebagian besar acara kalender itu di Daili, dan perubahannya disimpan di Google atau Outlook. Di formulir "Acara baru" kamu lalu juga bisa memilih kalender itu di bawah "Simpan ke": acaranya langsung disimpan di Google atau Outlook, sedangkan orang, pengingat, dan kategori yang kamu tambahkan tetap di Daili. Bagian 5 menjelaskan detailnya untuk Google, dan "Sinkronisasi dua arah dengan Outlook" di bawah menjelaskannya untuk Outlook. Kamu bisa memutus hubungan kapan saja; acara yang tersinkron dan kunci aksesnya lalu dihapus. Cara Daili menangani data Google Calendar — apa yang dibacanya, dengan siapa data itu dibagikan, dan bagaimana data itu dilindungi — dijelaskan di bagian 5. Tautan kalender (misalnya kalender sekolah) yang kamu tambahkan sebagai "Hanya saya" hanya terlihat olehmu; tautan yang ditambahkan untuk seluruh keluarga terlihat oleh setiap anggota. Untuk acara dari kalender Google atau Outlook atau dari tautan kalender, kami menyimpan judul, tempat, waktu, dan catatannya; catatan itu dibersihkan menjadi teks biasa dan dibatasi paling banyak 2.000 karakter, dan hanya ditampilkan kepada orang yang bisa melihat kalender tersebut. Untuk acara Google, kami juga menyimpan warnanya (salah satu warna acara milik Google sendiri), agar Daili bisa menampilkan acara itu dengan warna tersebut. Jika kamu menampilkan kalender ponselmu di widget Kalender, aplikasi menyalin acaranya untuk hari ini dan 14 hari berikutnya (judul, waktu, dan warna) ke penyimpanan widget di ponselmu; salinan ini juga tidak pernah keluar dari ponsel. Apakah sebuah kalender ponsel ditampilkan dengan warnanya sendiri juga hanya disimpan di ponselmu.

Edit di Daili (opsional). Acara dari kalender ponselmu, dari tautan kalender, atau dari kalender Google atau Outlook yang diatur ke "Hanya lihat" tidak bisa diubah di Daili. Jika kamu mengetuk Edit di Daili pada acara seperti itu, aplikasi membuka acara Daili baru yang sudah terisi judul, tempat, waktu, dan catatannya (jika ada). Tidak ada yang dikirim sampai kamu mengetuk Simpan, dan sebelumnya kamu bisa mengubah atau menghapus apa saja. Setelah disimpan, acara itu menjadi acara Daili biasa, yang disimpan di server kami seperti acara lain yang kamu buat: keluargamu bisa melihatnya kecuali kamu menjadikannya pribadi (jika acara itu berasal dari kalender yang di Daili hanya bisa kamu lihat dan kamu tidak memilih siapa pun untuknya, acara itu disimpan sebagai pribadi), dan aplikasi AI yang kamu hubungkan ke Daili bisa membacanya seperti acara-acaramu yang lain — kecuali selama acara itu tetap tertaut ke acara kalender Google atau Outlook (lihat bagian 5). Untuk acara dari kalender Google atau Outlook atau dari tautan kalender, acara Daili tetap tertaut ke acara aslinya: server kami menyimpan referensi kecil ke acara asli, menyembunyikan acara asli di dalam Daili selama tautan itu ada, dan saat waktu, judul, atau tempat acara asli berubah, acara Daili ikut mengambil perubahan itu. Jika kamu sendiri sudah mengubah detail itu, aplikasi bertanya dulu kepadamu; jika acara asli hilang dari kalendernya, aplikasi memberitahumu dan membiarkanmu menyimpan atau menghapus acara Daili; jika seluruh kalender yang ditautkan dihapus dari Daili, acara Daili tetap seperti apa adanya. Daili tidak pernah mengubah acara aslinya — kecuali jika acara itu milik kalender Google atau Outlook yang kamu tautkan dan kamu ubah ke "Dua arah": dalam hal itu, untuk acara Daili tertaut yang tidak berulang, perubahan yang kamu buat pada judul, tempat, atau waktunya juga disimpan di Google atau Outlook, dan saat kamu menghapusnya, Daili bertanya apakah acara itu dihapus "Hanya di Daili" atau di "Daili dan Google" (atau "Daili dan Outlook") (lihat bagian 5 dan "Sinkronisasi dua arah dengan Outlook" di bawah). Acara Daili yang kamu buat dan sama persis dengan acara di kalender yang ditautkan (judul dan waktu yang sama) ditautkan ke acara itu dengan cara yang sama — ini juga berlaku untuk acara yang kamu ambil dari kalender ponselmu sendiri, jika acara yang sama ada di kalender yang ditautkan. Selain itu, acara yang diambil dari kalender ponselmu disembunyikan di ponsel tersebut selama acara Daili-nya ada, dan tidak diperbarui — kalender ponselmu tetap di perangkatmu. Acara yang sejak akhir Oktober 2026 kamu salin dengan tombol sebelumnya, "Salin ke Daili", telah ditautkan satu kali ke acara aslinya dengan cara yang sama. Dasar hukum: pelaksanaan kontrak denganmu (Pasal 6(1)(b) GDPR).

Sinkronisasi dua arah dengan Outlook (opsional). Sinkronisasi dua arah untuk Outlook diluncurkan secara bertahap, jadi mungkin belum tersedia untukmu. Tanpa fitur ini, Daili hanya membaca kalender Outlook-mu. Hanya jika kamu mengubah salah satu kalender Outlook-mu ke "Dua arah" (di aplikasi: "Pilih kalender" → "Sinkronisasi" → "Dua arah"; aplikasi lebih dulu menjelaskan apa artinya, lalu halaman Microsoft sendiri meminta persetujuanmu), Daili meminta satu izin tambahan kepada Microsoft: Calendars.ReadWrite — membaca dan mengubah acara kalendermu. Microsoft memberikan izin ini untuk semua kalender di akunmu, tetapi Daili hanya menulis ke kalender yang kamu ubah ke "Dua arah", dan hanya ke kalender yang boleh kamu edit menurut Outlook. Jika kamu tidak mengizinkannya di halaman Microsoft, koneksimu tetap hanya baca. Dengan sinkronisasi dua arah, Daili mengubah, menghapus, atau menambah acara di Outlook hanya saat kamu sendiri mengubah, menghapus, atau menambah acara itu di Daili, dan hanya di kalender itu. Daili tidak pernah mengubah kalender Outlook-mu dengan sendirinya: proses latar belakang tidak pernah menulis ke dalamnya. Hanya orang yang menautkan kalender itu yang bisa melakukannya: anggota keluarga lain, layar dinding keluarga, layar TRMNL, dan aplikasi AI yang terhubung tidak pernah bisa mengubah apa pun di Outlook. Untuk itu, Daili hanya mengirim ke Microsoft judul, tempat, catatan, waktu mulai dan selesai acara, apakah acaranya sepanjang hari, dan zona waktunya — untuk acara berulang yang baru juga aturan pengulangannya, dan untuk acara baru sebuah ID acara teknis yang dibuat oleh Daili. Orang, pengingat, dan kategori tetap di Daili. Daili tidak pernah mengirim undangan dan tidak pernah menambahkan tamu: acara yang punya tamu, undangan dari orang lain, rapat online dan acara khusus Outlook lainnya, serta beberapa acara berulang yang dihitung berbeda oleh Outlook tetap hanya bisa dilihat di Daili. Agar sinkronisasi dua arah bisa berjalan, untuk setiap acara Outlook kami menyimpan jenis detail teknis yang sama seperti untuk Google (bagian 5, "Apa yang kami simpan"): ID Microsoft untuk acara itu dan serinya, sebuah cap versi, beberapa penanda, dan, jika acara itu harus tetap hanya bisa dilihat, hanya alasannya. Untuk kalender yang diatur ke "Dua arah", Daili juga meminta Microsoft memberi tahu server kami saat kalender itu berubah; pemberitahuan seperti itu hanya menyatakan bahwa kalendernya berubah dan tidak memuat detail acara apa pun. Untuk itu kami menyimpan ID pemberitahuan dari Microsoft, token rahasia (hanya sebagai hash), dan kapan pemberitahuan itu berakhir; pemberitahuan itu dihentikan saat kalender tidak lagi diatur ke "Dua arah", saat kamu menghapusnya dari Daili, memutus Outlook, atau menghapus akunmu. Mengubah kalender kembali ke "Hanya lihat", menghapusnya dari Daili, memutus Outlook, atau menghapus akun Daili-mu tidak menghapus apa pun di kalender Outlook-mu. Acara dari kalender Outlook tidak pernah sampai ke aplikasi AI yang kamu hubungkan (lihat "Aplikasi AI yang kamu hubungkan" di bawah). Kamu bisa mencabut akses Daili kapan saja: untuk akun Microsoft pribadi di account.live.com/consent/Manage, dan untuk akun kerja atau sekolah di halaman yang disediakan organisasimu untuk itu (tanyakan kepada administrator IT-nya). Setelah itu Daili tidak bisa lagi membaca atau mengubah kalender Outlook-mu; putuskan juga hubungannya di Daili untuk menghapus salinan yang kami simpan. Dasar hukum: pelaksanaan kontrak denganmu (Pasal 6(1)(b) GDPR).

Kamu bisa mengekspor data Siklus-mu sendiri sebagai file (dan mengimpornya lagi, misalnya di ponsel baru), dan menghapusnya di pengaturan Siklus ("Hapus semua data siklus"); menghapus akunmu di aplikasi juga menghapusnya di ponsel itu.

5. Data pengguna Google

Bagian ini menjelaskan bagaimana Daili mengakses, memakai, menyimpan, membagikan, dan melindungi data pengguna Google: data yang kami terima dari Google saat kamu menghubungkan Google Calendar, atau saat kamu masuk dengan Google — serta perubahan yang disimpan Daili ke Google Calendar-mu jika kamu memakai sinkronisasi dua arah.

Apa yang kami akses

Hanya jika kamu mengetuk "Hubungkan Google Calendar" dan menyetujuinya di layar persetujuan Google, Daili mendapat akses hanya baca dengan izin-izin berikut:

  • calendar.calendarlist.readonly — daftar kalendermu (nama dan warna), agar kamu bisa memilih kalender mana yang ditampilkan Daili;
  • calendar.events.readonly — acara dari kalender yang kamu pilih;
  • openid dan email — alamat e-mail akun Google, agar kamu bisa melihat akun mana yang terhubung.

Sinkronisasi dua arah (opsional). Sinkronisasi dua arah diluncurkan secara bertahap, jadi mungkin belum tersedia untukmu. Hanya jika kamu mengubah salah satu kalendermu ke "Dua arah" (di aplikasi: "Pilih kalender" → "Sinkronisasi" → "Dua arah"; aplikasi lebih dulu menjelaskan apa artinya, lalu halaman Google sendiri meminta persetujuanmu), Daili meminta satu izin tambahan:

  • calendar.events — melihat dan mengedit acara di semua kalendermu.

Google memberikan izin ini untuk semua kalender di akun Google-mu, tetapi Daili hanya menulis ke kalender yang kamu ubah ke "Dua arah", dan hanya ke kalender yang boleh kamu edit menurut Google. Jika kamu tidak mengizinkannya di halaman Google, koneksimu tetap hanya baca.

Tanpa sinkronisasi dua arah, Daili hanya membaca Google Calendar-mu. Dengan sinkronisasi dua arah, Daili membuat, mengubah, atau menghapus acara di Google hanya saat kamu sendiri menambah, mengubah, atau menghapus acara itu di Daili. Daili tidak pernah mengubah Google Calendar-mu dengan sendirinya. Hanya orang yang menautkan kalender itu yang bisa melakukannya: anggota keluarga lain, layar dinding keluarga, layar TRMNL, dan aplikasi AI yang terhubung tidak pernah bisa mengubah apa pun di Google. Untuk itu, Daili hanya mengirim ke Google judul, tempat, catatan, waktu mulai dan selesai acara, apakah acaranya sepanjang hari, dan zona waktunya — untuk acara berulang yang baru juga aturan pengulangannya, dan untuk acara baru sebuah ID acara teknis yang dibuat oleh Daili. Tidak ada hal lain yang dikirim ke Google: orang, pengingat, dan kategori tetap di Daili. Acara yang punya tamu, undangan dari orang lain, acara yang dikunci Google, dan acara khusus Google (misalnya ulang tahun atau di luar kantor) tetap hanya bisa dilihat di Daili, dan Daili tidak pernah mengirim e-mail undangan atau pembaruan kepada siapa pun. Mengubah kalender kembali ke "Hanya lihat", menghapusnya dari Daili, memutus Google, atau menghapus akun Daili-mu tidak menghapus apa pun di Google Calendar-mu.

Jika kamu masuk dengan Google (bagian 4), kami hanya menerima namamu, alamat e-mail, dan ID pengguna teknis, dan hanya memakainya untuk membuatmu masuk.

Bagaimana kami memakainya

Kami memakai data pengguna Google hanya untuk menampilkan acara dari kalender yang kamu pilih di dalam Daili: di kalender keluarga di aplikasi dan aplikasi web, di widget layar utamamu, di notifikasi ringkasan pagi dan malam jika kamu menyalakannya, dan di layar dinding keluarga jika keluargamu menghubungkannya. Jika kamu mengetuk Edit di Daili pada satu acara, kami juga memakai acara itu untuk mengisi acara Daili baru untukmu dan, selama acara itu tetap tertaut, untuk membawa perubahan waktu, judul, atau tempatnya yang terjadi kemudian ke acara Daili tersebut (lihat "Edit di Daili" di bagian 4). Jika kamu mengubah sebuah kalender ke "Dua arah", kami juga memakai data pengguna Google untuk menyimpan perubahan yang kamu buat di Daili ke kalender itu di Google, atas permintaanmu, dan untuk memeriksa sebelum setiap perubahan bahwa acaranya belum berubah di Google sementara itu dan bahwa Daili boleh mengubahnya. Kami tidak memakai data pengguna Google untuk iklan, tidak menjualnya, tidak memakainya untuk membuat profil, dan tidak memakainya untuk mengembangkan, meningkatkan, atau melatih model kecerdasan buatan atau pembelajaran mesin. Data Google Calendar tidak pernah dikirim ke fitur AI yang dijelaskan di bagian 4.

Apa yang kami simpan

Untuk setiap acara: judul, lokasi, waktu mulai dan selesai, apakah acaranya sepanjang hari, zona waktunya, warnanya (nomor warna Google untuk acara itu, jika ada), dan deskripsinya (catatan acara), yang dibersihkan menjadi teks biasa dan dibatasi paling banyak 2.000 karakter. Untuk setiap kalender yang dipilih: nama dan warnanya. Untuk setiap keluarga: warna Google mana yang cocok dengan kategori acara keluarga yang mana, jika ada anggota keluarga yang mengaturnya; setiap anggota keluarga bisa melihat dan mengubahnya, dan data ini dihapus bersama kategorinya atau keluarganya. Daili tidak pernah mengirim warna ke Google. Untuk koneksinya: alamat e-mail Google, izin apa saja yang kamu berikan, dan kunci akses (token OAuth) yang diberikan Google kepada kami. Agar sinkronisasi dua arah bisa berjalan, untuk setiap acara kami juga menyimpan ID teknis Google untuk acara itu dan untuk serinya, sebuah cap versi (etag), beberapa penanda teknis (misalnya bahwa catatannya tidak bisa dipertahankan persis atau bahwa waktunya tidak bisa diubah dari Daili), dan, jika acara itu harus tetap hanya bisa dilihat, hanya alasannya (misalnya "punya tamu"); untuk setiap kalender yang dipilih, apakah kalender itu diatur ke "Hanya lihat" atau "Dua arah", apakah Google mengizinkanmu mengeditnya, apakah kalender itu pilihanmu untuk acara baru, dan kapan pembaruan diminta. Untuk memutuskan apakah sebuah acara tetap hanya bisa dilihat, Daili melihat apakah acara itu punya tamu dan siapa penyelenggaranya, tetapi hanya menyimpan alasannya. Kami tidak menyimpan siapa saja tamunya, dan kami tidak menyimpan lampiran. Data ini disimpan di server Daili di Uni Eropa (bagian 7); aplikasi menyimpan salinannya di perangkatmu agar kalendermu juga bisa dipakai secara offline. Setiap perubahan yang dikirim Daili ke Google meninggalkan satu baris singkat di log teknis server kami yang berumur pendek: nomor internal kalender, jenis perubahan, hasilnya, dan berapa lama prosesnya — tidak pernah judul, tempat, atau catatan. Jika Google menolak sebuah perubahan, baris itu juga memuat pesan galat singkat dari Google sendiri.

Pemberitahuan perubahan dari Google. Untuk kalender yang diatur ke "Dua arah", Daili meminta Google memberi tahu server kami saat ada yang berubah di kalender itu, agar Daili bisa segera memperbaruinya. Pemberitahuan seperti itu hanya menyatakan bahwa kalendernya berubah; pemberitahuan itu tidak memuat acara atau detail acara apa pun. Untuk setiap kalender seperti itu, kami menyimpan ID saluran, ID pasangannya dari Google, token rahasia (hanya sebagai hash), dan kapan saluran itu berakhir. Saluran berakhir dengan sendirinya setelah beberapa hari dan diperbarui selama kalender itu tetap diatur ke "Dua arah". Saluran dihentikan saat kamu mengubah kalender itu ke "Hanya lihat", menghapusnya dari Daili, memutus Google, atau menghapus akunmu.

Dengan siapa kami membagikan, mentransfer, atau mengungkapkan data pengguna Google

Kami tidak menjual data pengguna Google, dan kami tidak membagikan, mentransfer, atau mengungkapkannya kepada siapa pun, kecuali dalam kasus-kasus berikut:

  • Anggota keluargamu — hanya kalender yang kamu tandai "Bagikan ke keluarga". Kalender yang kamu biarkan pribadi hanya terlihat olehmu.

Bagaimana kami melindungi data pengguna Google

  • Enkripsi saat transit: setiap koneksi antara aplikasi atau aplikasi web, server kami, dan Google memakai HTTPS (TLS).
  • Kunci akses terenkripsi: kunci akses Google (token OAuth) dienkripsi di basis data kami dengan AES-256. Kunci itu tidak pernah meninggalkan server kami dan tidak pernah dikirim ke aplikasi atau peramban.
  • Kontrol akses: server kami mengembalikan acara Google Calendar hanya kepada anggota keluarga yang sudah masuk, kepada layar dinding keluarga dengan kuncinya sendiri (hanya kalender yang dibagikan ke keluarga), dan kepada TRMNL seperti dijelaskan di atas.   • Akses staf terbatas: hanya pengembang Daili (bagian 1) yang punya akses administratif ke server dan basis data.

6. Bagaimana kami melindungi datamu

8. Berapa lama kami menyimpan data

Datamu bertahan selama akunmu ada. Jika kamu menghapus akunmu, akun langsung dinonaktifkan, disimpan selama masa tenggang 30 hari (kalau kamu berubah pikiran — kamu bisa memulihkannya lewat tautan e-mail), lalu dihapus permanen. Kamu bisa mengekspor datamu sebagai berkas kapan saja (Pengaturan → Profil → Unduh data saya). Saat akunmu dihapus, kami juga menghapus catatan kami tentang langganan Daili Plus-mu dan meminta RevenueCat menghapus catatannya tentang dirimu. Apple dan Google menyimpan catatan pembelianmu sendiri berdasarkan kebijakan privasi mereka. Jika kamu mencentang "Kirimi saya email sekali saat ini membaik", kami menyimpan alamat e-mailmu untuk satu e-mail itu hingga 12 bulan setelah penghapusan (lihat "Saat kamu menghapus akunmu" di bagian 4).

Kami menyimpan cadangan server (backup) selama sekitar 4 minggu (cadangan lengkap setiap minggu ditambah perubahan harian), di server dan di penyimpanan Hetzner di Jerman. Jadi, setelah akunmu dihapus, datanya masih bisa tersimpan di cadangan hingga sekitar 4 minggu lagi; setelah itu datanya dihapus permanen. Kami memakai cadangan hanya untuk memulihkan Daili setelah terjadi gangguan — tidak pernah untuk memulihkan atau melihat akun satu per satu.
