Kebijakan Privasi

Aplikasi Daili, app.daili.app dan daili.app · Terakhir diperbarui: 5 September 2026

Daili adalah perencana keluarga yang privat. Kami membangunnya agar rencana keluargamu menjadi milik keluargamu: tanpa iklan, tanpa pelacakan, tanpa penjualan data. Halaman ini menjelaskan dengan bahasa sederhana data apa yang dibutuhkan aplikasi, untuk apa, dan apa saja hakmu.

2. Situs web ini

daili.app adalah situs statis. Situs ini tidak memasang cookie apa pun, tidak memakai alat analitik apa pun, dan tidak memuat font atau skrip pihak ketiga. Penyedia hosting kami otomatis menyimpan log server berumur pendek (alamat IP, waktu, halaman yang diminta) demi keamanan; kami tidak memakainya untuk hal lain. Dasar hukum: kepentingan sah kami atas situs yang aman (Pasal 6(1)(f) GDPR).

3. Aplikasi web (app.daili.app)

Daili juga berjalan di peramban, di app.daili.app. Aplikasi web tidak memasang cookie apa pun dan tidak memakai alat analitik apa pun. Font disajikan dari server kami sendiri, jadi saat dijalankan aplikasi web tidak memuat font atau skrip pihak ketiga.

Alih-alih cookie, peramban menyimpan token masukmu di penyimpanan lokal miliknya sendiri. Token itulah yang membuktikan kepada server kami bahwa sebuah permintaan berasal darimu, dan keluar dari akun akan menghapusnya. Di sampingnya, peramban menyimpan beberapa pengaturan tampilan agar aplikasi terlihat sama saat berikutnya dibuka: bahasa dan tema, tampilan kalender yang terakhir kamu pakai, kotak mana yang kamu tampilkan di layar utama, apakah bilah samping diciutkan, dan waktu pengingat bawaanmu. Pengaturan itu tetap di perangkatmu, tidak pernah dikirim kepada kami, dan bertahan sampai kamu menghapus data situs di peramban. Semua yang disimpan di sini bersifat mutlak diperlukan untuk masuk atau merupakan preferensi yang kamu pilih sendiri — karena itu tidak ada spanduk cookie.

Masuk dengan Google atau Apple (opsional). Hanya jika kamu memilih masuk lewat akun sosial, sebuah jendela terbuka melalui Firebase Authentication, persis seperti di aplikasi ponsel. Jika kamu masuk dengan alamat e-mail dan kata sandi, tidak ada kode Google atau Apple yang berjalan sama sekali.

Notifikasi peramban (opsional). Hanya jika kamu menyalakannya dan peramban memberi izin, aplikasi web mendaftarkan service worker dan mengambil token perangkat dari Firebase Cloud Messaging. Token itu beserta nomor perangkatnya lalu disimpan di penyimpanan lokal, dan salinan token masukmu disimpan di basis data peramban (IndexedDB) agar tombol pada sebuah notifikasi tetap bekerja ketika tidak ada tab Daili yang terbuka. Mematikan notifikasi, atau keluar dari akun, menghapus semuanya.

4. Data yang diproses aplikasi

Data akun. Saat kamu mendaftar, kami menyimpan nama tampilan, alamat e-mail, dan kata sandimu (hanya sebagai hash yang aman — kami tidak bisa membacanya). Opsional: foto profil dan preferensi bahasa. Dasar hukum: pelaksanaan kontrak denganmu (Pasal 6(1)(b) GDPR).

Masuk dengan Google atau Apple (opsional). Jika kamu memilih masuk lewat akun sosial, autentikasi berjalan melalui Firebase Authentication (Google Ireland Ltd.). Kami menerima namamu, alamat e-mail (Apple memungkinkanmu menyembunyikannya di balik alamat penerus), dan ID pengguna teknis. Kami tidak pernah melihat kata sandi Google atau Apple-mu.

Konten keluarga. Semua yang dibuat keluargamu di aplikasi disimpan di server kami agar anggota keluargamu bisa melihatnya: acara kalender dan pengingat, daftar belanja dan tugas, resep dan rencana makan, ulang tahun dan perayaan, alamat kalender eksternal yang dilanggan, serta profil anggota keluarga — termasuk profil terkelola untuk anak (nama, ulang tahun opsional, foto opsional) yang dibuat dan dikendalikan orang tua. Konten ini hanya terlihat oleh anggota keluargamu, tidak pernah oleh pengguna lain dan tidak pernah untuk umum.

Kalender terhubung (opsional). Jika kamu menambahkan kalender ponselmu, acara-acara itu dibaca dan ditampilkan hanya di perangkatmu — tidak pernah diunggah ke server kami, dan keluargamu tidak bisa melihatnya. Jika kamu menghubungkan kalender Google atau Outlook, Daili membaca kalender yang kamu pilih (hanya baca) dan menyimpan acaranya di server kami agar kamu — dan, hanya jika kamu mau, keluargamu — bisa melihatnya di kalender keluarga. Kamu bisa memutus hubungan kapan saja; acara yang tersinkron dan kunci aksesnya lalu dihapus.

Kontak (opsional). Jika kamu memakai "impor ulang tahun", aplikasi menampilkan buku alamatmu di perangkatmu agar kamu bisa memilih entri; hanya nama dan tanggal ulang tahun yang kamu centang yang dikirim ke server kami. Buku alamatnya sendiri tidak pernah diunggah.

Brankas foto & dokumen. Berkas di dalam brankas disimpan hanya di perangkatmu. Berkas itu tidak pernah diunggah ke server kami dan bukan bagian dari cadangan apa pun yang kami simpan.

Notifikasi push. Untuk mengirim pengingat, aplikasi mendaftarkan token perangkat teknis ke Firebase Cloud Messaging (Google). Kamu bisa mematikan notifikasi kapan saja di pengaturan sistem; pengingat lalu berhenti begitu saja.

E-mail. E-mail terkait akun (verifikasi, atur ulang kata sandi, undangan) kami kirim lewat Brevo, penyedia e-mail di Uni Eropa. Kami tidak mengirim buletin maupun e-mail pemasaran.

Yang tidak dikumpulkan aplikasi. Tidak ada lokasi. Tidak ada ID iklan. Tidak ada alat analitik atau pelacakan di dalam aplikasi. Buku alamatmu dan kalender ponselmu tetap di perangkatmu.

5. Di mana datamu berada

Server Daili dihosting oleh Host Europe GmbH di Uni Eropa (Jerman). Firebase Authentication dan Firebase Cloud Messaging adalah layanan Google; Google dapat memproses data teknis terbatas (seperti token perangkat) di server di luar Uni Eropa berdasarkan klausul kontraktual standar Uni Eropa.

6. Berapa lama kami menyimpan data

Datamu bertahan selama akunmu ada. Jika kamu menghapus akunmu, akun langsung dinonaktifkan, disimpan selama masa tenggang 30 hari (kalau kamu berubah pikiran — kamu bisa memulihkannya lewat tautan e-mail), lalu dihapus permanen. Kamu bisa mengekspor datamu sebagai berkas kapan saja (Pengaturan → Profil → Unduh data saya).

7. Anak-anak

Daili dibuat untuk keluarga. Akun anak dibuat dan dikelola oleh orang tua atau wali: baik sebagai profil terkelola tanpa login, maupun lewat undangan pribadi dari admin keluarga. Orang tua bisa menghapus profil seorang anak beserta datanya kapan saja.

8. Hakmu

  • Akses ke data yang kami simpan tentangmu (ekspor di dalam aplikasi mencakup ini)
  • Perbaikan data yang salah, penghapusan, dan pembatasan pemrosesan
  • Portabilitas data (berkas ekspor)
  • Keberatan atas pemrosesan yang didasarkan pada kepentingan sah

Tulis saja ke support@daili.app. Kamu juga berhak mengadu ke Otoritas Perlindungan Data Austria (Datenschutzbehörde, dsb.gv.at).

9. Perubahan

Jika Daili mendapat fitur baru yang mengubah cara data ditangani, kami akan memperbarui halaman ini dan mencantumkan tanggalnya di bagian atas.
