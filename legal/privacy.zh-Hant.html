隱私權政策

Daili 應用程式、app.daili.app 和 daili.app · 最後更新：2026年9月5日

Daili 是一款私密的家庭行程助手。我們這樣設計，是為了讓你家的安排屬於你家：沒有廣告，沒有追蹤，不出售資料。本頁用平實的語言說明應用程式需要哪些資料、為什麼需要，以及你擁有哪些權利。

2. 本網站

daili.app 是一個靜態網站。它不設置任何 Cookie、不使用任何分析工具，也不載入任何第三方字型或指令碼。我們的主機服務商基於安全考量會自動保留短期的伺服器日誌（IP 位址、時間、請求的頁面）；我們不會將其用於其他用途。法律依據：我們對網站安全運作的正當利益（GDPR 第6條第1項(f)款）。

3. 網頁版（app.daili.app）

Daili 也可以在瀏覽器中執行，網址是 app.daili.app。網頁版不設置任何 Cookie，也不使用任何分析工具。字型由我們自己的伺服器提供，因此啟動時網頁版不載入任何第三方字型或指令碼。

網頁版不用 Cookie，而是由瀏覽器把你的登入權杖存放在它自己的本機儲存空間中。這個權杖向我們的伺服器證明某個請求來自你本人，登出時會被刪除。在它旁邊，瀏覽器還會保存幾項顯示設定，好讓應用程式下次看起來一樣：語言與主題、你上次使用的行事曆檢視、主畫面上顯示哪些方塊、側邊欄是否收合，以及你的預設提醒時間。這些設定留在你的裝置上，從不傳送給我們，直到你清除瀏覽器的網站資料才會消失。這裡保存的一切，要嘛是登入所必需的，要嘛是你自己選擇的偏好——所以沒有 Cookie 橫幅。

使用 Google 或 Apple 登入（選用）。只有當你選擇社群登入時，才會開啟一個經由 Firebase Authentication 的彈出視窗，和手機應用程式中完全一樣。如果你用電子郵件和密碼登入，Google 或 Apple 的程式碼根本不會執行。

瀏覽器通知（選用）。只有當你開啟通知並且瀏覽器授予權限時，網頁版才會註冊一個 service worker，並從 Firebase Cloud Messaging 取得裝置權杖。該權杖及其裝置編號隨後保存在本機儲存空間中；同時，你的登入權杖的一份副本會保存在瀏覽器資料庫（IndexedDB）裡，這樣即使沒有開啟 Daili 分頁，通知上的按鈕也仍然可用。關閉通知或登出會把這些全部清除。

4. 應用程式處理的資料

帳號資料。註冊時我們會保存你的顯示名稱、電子郵件和密碼（僅以安全雜湊形式保存——我們無法讀取）。選用：大頭貼和語言偏好。法律依據：履行與你之間的契約（GDPR 第6條第1項(b)款）。

使用 Google 或 Apple 登入（選用）。如果你選擇社群登入，身分驗證會經由 Firebase Authentication（Google Ireland Ltd.）。我們會收到你的姓名、電子郵件（Apple 允許你用轉寄位址隱藏它）以及一個技術性使用者 ID。我們從不會看到你的 Google 或 Apple 密碼。

家庭內容。你家在應用程式中建立的一切都保存在我們的伺服器上，好讓家庭成員能看到：行事曆活動與提醒、購物和待辦清單、食譜與菜單、生日與紀念日、已訂閱的外部行事曆位址，以及家庭成員資料——包括由家長建立並管理的兒童受管資料（姓名、選填生日、選填照片）。這些內容只有你家的成員能看到，其他使用者看不到，也從不公開。

連結的行事曆（選用）。如果你加入手機上的行事曆，這些活動只在你的裝置上讀取和顯示——絕不會上傳到我們的伺服器，你的家人也看不到。如果你連結 Google 或 Outlook 行事曆，Daili 會讀取你選擇的行事曆（唯讀），並把其中的活動保存在我們的伺服器上，好讓你——以及在你選擇的情況下你的家人——能在家庭行事曆中看到它們。你隨時可以中斷連結；屆時同步的活動和存取金鑰會被刪除。

通訊錄（選用）。如果你使用「匯入生日」，應用程式會在你的裝置上顯示通訊錄供你挑選項目；只有你勾選的姓名和生日會傳送到我們的伺服器。通訊錄本身絕不會上傳。

照片與文件保險箱。保險箱中的檔案只保存在你的裝置上。它們絕不會上傳到我們的伺服器，也不屬於我們持有的任何備份。

推播通知。為了送達提醒，應用程式會向 Firebase Cloud Messaging（Google）註冊一個技術性裝置權杖。你隨時可以在系統設定中關閉通知；提醒隨之停止。

電子郵件。帳號相關郵件（驗證、重設密碼、邀請）透過歐盟郵件服務商 Brevo 寄送。我們不寄送電子報，也不寄送行銷郵件。

應用程式不蒐集的內容。不蒐集位置。沒有廣告 ID。應用程式內沒有分析或追蹤工具。你的通訊錄和手機行事曆都留在你的裝置上。

5. 你的資料存放在哪裡

Daili 伺服器由 Host Europe GmbH 代管於歐盟（德國）。Firebase Authentication 和 Firebase Cloud Messaging 是 Google 的服務；Google 可能依據歐盟標準契約條款，在歐盟以外的伺服器上處理有限的技術資料（例如裝置權杖）。

6. 資料保留多久

只要你的帳號存在，資料就會保留。如果你刪除帳號，它會立即停用，保留30天的寬限期（以防你改變主意——可透過郵件連結復原），之後永久刪除。你隨時可以把資料匯出為檔案（設定 → 個人資料 → 下載我的資料）。

7. 兒童

Daili 是為家庭而做的。兒童帳號由家長或監護人建立並管理：既可以是無須登入的受管資料，也可以透過家庭管理員的個人邀請。家長隨時可以移除孩子的資料及其內容。

8. 你的權利

  • 存取我們持有的關於你的資料（應用程式內匯出即可滿足）
  • 更正錯誤資料、刪除資料、限制處理
  • 資料可攜（匯出的檔案）
  • 反對基於正當利益的處理

寫信到 support@daili.app 即可。你也有權向奧地利資料保護局（Datenschutzbehörde, dsb.gv.at）提出申訴。

9. 變更
